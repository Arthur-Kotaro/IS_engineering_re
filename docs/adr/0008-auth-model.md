# ADR-0008: Модель аутентификации (X-User-ID)

## Статус
Accepted

## Дата
2026-09-26

## Решение

- Nginx — единая точка входа.
- Auth Service — только /verify.
- Сервисы — принимают X-User-ID, X-User-Role, X-Impersonated-By от nginx. Доверяют.
- Изоляция: порты сервисов доступны только в локальной сети. Bind на 127.0.0.1 + firewall.
- UI Composer — пробрасывает заголовки в сервисы при запросах sources.

## Заголовки

| Заголовок | Значение |
|---|---|
| X-User-ID | Идентификатор пользователя. |
| X-User-Role | Роли через запятую, либо super_admin. |
| X-Impersonated-By | Кто действует на самом деле (при имперсонации). |

## Что НЕ делается

- Сервисы не декодируют JWT.
- Сервисы не проверяют подпись.
- Сервисы доверяют nginx.

## Риск

Если порт сервиса доступен извне — обход авторизации. Митигация: bind на 127.0.0.1 + firewall.
