# ADR 0014. Клиентские рендеринг-движки (PRE, BDERE, GDERE)

**Дата:** 2026-10-25
**Status:** Accepted

## Контекст

Клиент (Qt6 QML) обрастает сложными инструментами: диаграммы Ганта, блочные диаграммы. Они требуют отдельных окон (без TopBar), своих моделей данных и инструментов.

## Решение

В клиенте выделены три **независимых** рендеринг-движка:

1. **PRE (Page Rendering Engine)** — рендеринг страниц (формы, таблицы). Работает внутри вкладок. Существующий `JsonUiRenderer`.
2. **BDERE (Block Diagram Editor Rendering Engine)** — рендеринг блочных диаграмм. Отдельное окно (`BlockEditorWindow`). Отложен.
3. **GDERE (Gantt Diagram Editor Rendering Engine)** — рендеринг диаграмм Ганта. Отдельное окно (`GanttEditorWindow`). В работе.

**Ключевые принципы:**
- BDERE и GDERE **независимы** (никакой общей `DiagramModelBase`). Их сходство поверхностно.
- Открытие окон редакторов реализуется через сигналы `WidgetBridge` → `MainWindow`.
- PRE поддерживает кастомные виджеты (например, `ProjectList`) через генераторы в `WidgetGenerators.cpp`.

## Последствия

- Клиент может расширяться новыми движками без переделки существующих.
- Каждый движок имеет свою модель данных и логику.
- PRE остаётся универсальным для страниц.
