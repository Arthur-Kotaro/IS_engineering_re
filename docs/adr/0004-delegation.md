# ADR-0004: Три типа делегирования

## Статус
Accepted

## Дата
2026-09-26

## Решение

Три типа делегирования:

| Тип | Инициатор | Получатель | Основание | Механизм |
|---|---|---|---|---|
| Обратное | Начальник | Прямой подчинённый | Иерархия | «Войти как» → DelegatedWindow |
| Прямое | Начальник | Прямой подчинённый | Явный акт | «Войти как» → DelegatedWindow |
| Временное | Начальник | Подчинённый Б (полномочия подчинённого А) | Явный акт | «Войти как А» → DelegatedWindow |

## Правила

- Один реципиент на одно прямое/временное.
- Только прямой подчинённый.
- Передача дальше запрещена.
- Рекурсия запрещена.
- Реципиент не может создавать делегации (в режиме имперсонации — 403).
- Отзыв: инициатор или суперадмин.
- Начальник не создаёт делегацию от имени подчинённого.
- При увольнении/блокировке донора — ликвидация через событие от User.

## Delegation Service

- Хранит только DIRECT и TEMPORARY.
- Обратное — часть иерархии, не хранится.
- Универсален, без scope, без знания о ресурсах.
