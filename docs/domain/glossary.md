# Глоссарий ERP «Engineering:re»

## Пользователи и иерархия

| Термин | Определение |
|---|---|
| Пользователь | Учётная запись в User Service. Имеет `user_id`, `user_name`, `email`, роли. |
| Роль | Глобальная роль пользователя в системе (`admin`, `manager`, `hr`, `planner`, `user`, ...). Хранится в User Service. |
| Должность | Отображаемое название позиции пользователя. Выводится из ролей. |
| Иерархия | Отношение `head_id`: у пользователя один непосредственный руководитель. 1 уровень, не транзитивно. |
| Подчинённый | Пользователь, у которого `head_id` указывает на данного. |
| Начальник | Пользователь, у которого есть подчинённые. |

## Права и делегирование

| Термин | Определение |
|---|---|
| Право | Разрешение на действие над ресурсом. |
| Прямое право | Право, назначенное пользователю явно (членство в проекте с ролью). |
| Право через иерархию | Начальник наследует права подчинённого (1 уровень). |
| Право через делегацию | Право, полученное через явную передачу от донора. |
| Обратное делегирование | Начальник действует от имени подчинённого. Не требует акта. Всегда доступно. |
| Прямое делегирование | Начальник временно передаёт свои полномочия прямому подчинённому. Явный акт. |
| Временное делегирование | Начальник передаёт полномочия подчинённого А подчинённому Б. Явный акт. |
| Донор | Пользователь, чьи полномочия передаются. |
| Реципиент | Пользователь, получающий полномочия. |
| Инициатор | Пользователь, создающий делегацию. |
| Имперсонация | Действие от имени другого пользователя. Через токен с `impersonated_by`. |
| «Войти как …» | Плитка Navigation Service для входа в систему с полномочиями донора. |

## Workflow

| Термин | Определение |
|---|---|
| Workflow | Последовательность шагов для достижения бизнес-цели. YAML-файл. |
| Шаг workflow | Один экран. Имеет шаблон, события, переходы. |
| Шаблон | YAML-описание UI-страницы. Загружается UI Composer. |
| Виджет | UI-элемент в шаблоне (TextField, Button, Table, ...). |
| Событие | Действие пользователя (click, input, submit, row_select, ...). |
| Сессия workflow | Состояние пользователя в workflow. Хранится в Redis. `session_id`, `current_step`, `data`, `history`. |
| UI Composer | Сервис, генерирующий JSON-описания страниц по шаблонам и workflow. |

## Проекты и мастерграфики

| Термин | Определение |
|---|---|
| Проект | Единица планирования. Имеет команду, типологию, приоритет. |
| Мастерграфик | Диаграмма Ганта верхнего уровня проекта. |
| Локальный график | Подпроект или фаза внутри мастерграфика. |
| Работа | Атомарная единица в графике. |
| Зависимость | Связь между работами (FS, SS, FF, SF). |
| Веха | Точка без длительности. |
| Ресурс | Исполнитель, команда или оборудование. |

## Инфраструктура

| Термин | Определение |
|---|---|
| API Gateway | Nginx. Единая точка входа для клиента. |
| Auth Service | Валидатор JWT. Один эндпоинт `/verify`. |
| User Service | Issue JWT, управление пользователями и ролями. |
| Blacklist | Список отозванных JWT. Redis. |
| Плитка | Элемент рабочего стола клиента. Ведёт на endpoint. |
| X-User-ID | Заголовок с идентификатором пользователя от nginx. |
| X-Impersonated-By | Заголовок с реальным действующим пользователем при имперсонации. |
