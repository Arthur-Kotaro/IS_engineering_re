# Глоссарий ERP «Engineering:re»

## Пользователи и иерархия

| Термин | Определение |
|---|---|
| **Пользователь** | Учётная запись в User Service. `user_id`, `user_name`, `email`, роли. |
| **Роль** | Глобальная роль в системе: `admin`, `hr`, `manager`, `user`, `super_admin`. Хранится в User Service. |
| **Должность** | Отображаемое название позиции. Выводится из ролей на клиенте. |
| **Иерархия** | Отношение `head_id`: у пользователя один непосредственный руководитель. **1 уровень**, не транзитивно. |
| **Подчинённый** | Пользователь, у которого `head_id` указывает на данного. |
| **Начальник** | Пользователь, у которого есть подчинённые (`head_id` у кого-то = его id). |
| **Прямой подчинённый** | Непосредственный подчинённый (1 шаг по `head_id`). |

## Права и делегирование

| Термин | Определение |
|---|---|
| **Право** | Разрешение на действие над ресурсом (`view_project`, `edit_mastergraphic`, ...). |
| **Роль в проекте** | `owner`, `manager`, `editor`, `viewer`. Хранится в `project_members`. |
| **Прямое право** | Право, назначенное пользователю через членство в проекте. |
| **Право через иерархию** | Начальник действует от имени подчинённого (1 уровень). |
| **Право через делегацию** | Право, полученное через явную передачу от донора. |
| **Обратное делегирование** | Начальник действует от имени подчинённого. Не требует акта. **Не хранится** в Delegation Service. |
| **Прямое делегирование** | Начальник передаёт свои полномочия прямому подчинённому. Явный акт. Хранится. |
| **Временное делегирование** | Начальник передаёт полномочия подчинённого А подчинённому Б. Явный акт. Хранится. |
| **Донор** | Пользователь, чьи полномочия передаются (`delegator_id`). |
| **Реципиент** | Пользователь, получающий полномочия (`delegate_id`). |
| **Инициатор** | Пользователь, создающий делегацию (`initiator_id`). |
| **Имперсонация** | Действие от имени другого пользователя. Через токен с `impersonated_by`. |
| **«Войти как …»** | Плитка Navigation Service для входа в систему с полномочиями донора. |
| **DelegatedWindow** | Отдельное окно клиента для работы от имени донора. |

## Workflow

| Термин | Определение |
|---|---|
| **Workflow** | Последовательность шагов для бизнес-цели. YAML-файл в `workflows/`. |
| **Шаг workflow** | Один экран. Имеет шаблон, события, переходы. |
| **Шаблон** | YAML-описание UI-страницы. Загружается UI Composer. |
| **Виджет** | UI-элемент в шаблоне (`TextField`, `Button`, `Table`, ...). |
| **Событие** | Действие пользователя: `click`, `input`, `submit`, `change`, `row_select`. |
| **Сессия workflow** | Состояние пользователя в workflow. Redis DB 1. TTL 1 час. `session_id`, `current_step`, `data`, `history`. |
| **UI Composer** | Сервис, генерирующий JSON-описания страниц по шаблонам и workflow. |
| **`sources`** | Запросы к бизнес-сервисам при рендеринге шаблона. |
| **`session.data`** | Данные, накопленные в workflow между шагами. |
| **`context`** | Метаданные сессии в ответе UI Composer: `session_id`, `current_step`, `workflow_name`. |

## Проекты и мастерграфики

| Термин | Определение |
|---|---|
| **Проект** | Единица планирования. Имеет команду, типологию, приоритет, статус. |
| **Статус проекта** | `draft`, `active`, `suspended`, `completed`, `cancelled`. |
| **Мастерграфик** | Диаграмма Ганта верхнего уровня проекта. |
| **Локальный график** | Подпроект или фаза внутри мастерграфика. |
| **Работа** | Атомарная единица в графике. |
| **Зависимость** | Связь между работами (FS, SS, FF, SF). |
| **Веха** | Точка без длительности. |
| **Ресурс** | Исполнитель, команда или оборудование. |

## Инфраструктура

| Термин | Определение |
|---|---|
| **API Gateway** | Nginx. Единая точка входа для клиента. |
| **Auth Service** | Валидатор JWT. Один эндпоинт `/verify`. Читает blacklist из Redis. |
| **User Service** | Issue JWT, управление пользователями и ролями. Отдельный репозиторий. |
| **Blacklist** | Список отозванных JWT. Redis DB 0. Ключ `blacklist:{jti}`. |
| **Имперсонация-сессия** | Запись в Redis DB 0: `impersonation:{uuid}` = `recipient_id`. Инвалидируется при закрытии. |
| **Плитка** | Элемент рабочего стола клиента. Ведёт на endpoint. |
| **X-User-ID** | Заголовок с идентификатором пользователя. Ставит nginx. |
| **X-User-Role** | Заголовок с ролями через запятую или `super_admin`. |
| **X-Impersonated-By** | Заголовок с реальным действующим пользователем при имперсонации. |
| **X-Impersonation-Id** | Заголовок с id имперсонации. Используется для инвалидации. |
| **X-Internal-Key** | Заголовок для `/internal/*` эндпоинтов. |
