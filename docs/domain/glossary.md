# Глоссарий платформы

> Термины платформы «Engineering:re». Не путать с глоссарием
> предметной области ВАЗ/УПП — см. `domain/enterprise/glossary.md`.

## Архитектура и инфраструктура

| Термин | Значение |
|--------|----------|
| UI Composer | Сервис, генерирующий workflow-страницы из шаблонов |
| Navigation Service | Сервис навигации и плиток |
| Auth Service | Сервис аутентификации и авторизации |
| Delegation | Делегирование прав |
| Impersonation | Имперсонация (вход от имени другого пользователя) |
| Access model | Модель доступа |
| Discovery service | Сервис обнаружения экземпляров бизнес-МС |
| Workflow | Сценарий работы, генерируемый UI Composer |
| Плитка (tile) | Элемент навигации, привязанный к роли, должности или универсальный |

## Модели

| Термин | Значение |
|--------|----------|
| Position | Должность (одна у пользователя) |
| Role | Роль (несколько у пользователя, через `users_roles`) |
| Department | Подразделение (одно у пользователя, иерархия через `parent_dept_id`) |
| `project_roles` | Справочник проектных ролей |
| `project_members` | Участники проекта: `member_id` + `role_code` + `user_id` |
| `tiles_by_role` | Плитки по ролям |
| `tiles_by_position` | Плитки по должностям |
| `tiles_universal` | Универсальные плитки |

## Базовый универсальный бизнес-МС

| Термин | Значение |
|--------|----------|
| Бизнес-МС | Базовый универсальный бизнес-микросервис |
| Экземпляр бизнес-МС | Один из множества одинаковых по коду сервисов |
| Специализация «на лету» | Доработка экземпляра после выхода в эксплуатацию |
| ЛГ | Локальный график (создаётся бизнес-МС) |
| МГ | Мастерграфик |

## Статусы и модели

| Термин | Значение |
|--------|----------|
| JWT | JSON Web Token: `position` (одна) + `roles` (список) |
| Blacklist | Список отозванных JWT (Redis DB 0) |
| `X-User-Position` | HTTP-заголовок с должностью |
| `X-User-Role` | HTTP-заголовок с ролью |
