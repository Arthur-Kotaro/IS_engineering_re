## Условия проведения AVES

1. КД достигла зрелости.
2. Номинированы все поставщики.
3. Заключены серийные договора.
4. Спроектирована и изготовлена оснастка для серийного производства.
5. Разработана ТД для серийного производства.
6. Персонал серийного производства прошёл предварительное обучение.
