# Коммуникации прото-РП

> Источник: ЧАСТЬ 14 полной документации.

| Параметр | Значение |
|----------|----------|
| Отслеживание | Все события от запроса до передачи |
| Опрос участников | Регулярный, по своей инициативе |
| Формат | Совещания, созвоны, живые встречи |
| Инициатива | Сам собирает информацию |
| Отчётность | Произвольная форма, регулярная актуализация |
| Кому передаёт | Главному инженеру (иногда — начальнику УПП) |
| Информация сама | Редко приходит — он её вытягивает |
