| Классический случай | Да |

| Состав | Полный |
| Документ | ТЗ обязательно |

## Тип 2. Ретрофит

| Параметр | Значение |
|----------|----------|
| Русское | Ретрофит |
| English | Retrofit |
| Инициатор | Проект |
| Что прилагается | Состав с минимумом наименований КИ |
| Что в составе | Только те КИ, которые нужно установить |
| Что делает УПП | Получает физический образец для переоборудования |
| Кто передаёт образец | Те, у кого он находится: подразделение, проводившее испытания, либо подразделение, проводившее калибровки |
| Документ приёма | Акт приёма-передачи |
| Что делает УПП дальше | Проводит переоборудование |
| Кому отдаёт | Заказчику работ |
| Что с лишними КИ | По умолчанию — утилизация |
| Если проект запросил сохранить | Остатки на склад или ответственному лицу по накладной |
| Акт на переоборудование | Почти как классическое задание |
| Цель | Замена части КИ |
| Пример | Замена модуля впуска ДВС |
| Преимущество | Не нужно изготавливать новый ДВС |
| Результат | Объект приобретает новые технические характеристики |
| После | Снова испытания |
| Отличие от мула | Ретрофит — переоборудование объекта, ранее изготовленного в УПП и прошедшего испытания |

## Тип 3. BUK (Body, Unit, Kit)

| Параметр | Значение |
|----------|----------|
| Русское | BUK (кузов, unit, kit) |
| English | BUK (Body, Unit, Kit) |
| Аббревиатура | BUK = Body + Unit + Kit |
| Прежняя аббревиатура | CUK — пережиток прошлого (концерн Рено) |
| Категория | BUK — это категория |
| В запросе | Должно быть что-то одно из трёх подкатегорий |

### Подтип 3.1. Kit

| Параметр | Значение |
|----------|----------|
| English | Kit |
| Что предполагает | Обеспечение КИ по полному циклу |
| Включая | Комплектование на складе |
| Без | Последующей сборки |
| Что передаётся | Комплект КИ россыпью |
| Кому | Заказчику работ |
| Кто комплектует | Склад |
| Документы | Накладная + акт |
| Комплект формируется | На основании состава |
| Тара и упаковка | Если требуются |

### Подтип 3.2. Body (Кузов)

| Параметр | Значение |
|----------|----------|
| English | Body |
| Что делают | Изготовить кузов автомобиля |
| Вариант 1 | С 0 |
| Вариант 2 | Доработка серийного кузова |
| Если доработка | УПП выписывает кузов из серийного производства по ранее описанной схеме |
| Кому | Заказчику работ |
| Кто решает: с 0 или доработка | Технолог + прото-РП |
| Согласование с заказчиком | Обязательно |
| Формат согласования | Email |

### Подтип 3.3. Unit

| Параметр | Значение |
|----------|----------|
| English | Unit |
| Что делают | Изготовить кусок кузова автомобиля |
| Чаще | Вырезается из серийного кузова |
| Иногда | Можно изготовить |
| Затем | Обеспечить необходимыми КИ |
| Затем | Смонтировать на куске кузова КИ |
| Что передаётся | Получившееся изделие (unit) |
| Кому | Заказчику работ |
| Кто решает: вырезать или изготовить | Технолог + прото-РП |
| Согласование с заказчиком | Обязательно |
| Формат согласования | Email |

## Тип 4. Доработка

| Параметр | Значение |
|----------|----------|
| Русское | Запрос на доработку |
| English | Rework Request |
| Инициатор | Проект |
| Что получает УПП | Заготовку |
| Альтернатива | Заказывает серийную деталь |
| Что делает | Вносит изменения в конструкцию |
| Кому передаёт | Заказчику работ |
| Особенность 1 | Вместо ТЗ выпускается доводочное задание (ДЗК) |
| Особенность 2 | Работа над одной-тремя простыми КИ |
| Важно | Не узлами, а именно КИ |
| Особенность 3 | Изготовление не с 0, а доработка существующего изделия |
| ДЗК vs ТЗ | Не отличается от ТЗ. Почти. Будем считать, что не отличается |
| Ограничения по материалам | Вопрос не понят — открыт |
| Отличие от ретрофита | Ретрофит — разборный объект, замена частей. Доработка — изменение геометрии/размеров КИ. Обычно обработка металлов резанием, сварка |

## Тип 5. Поддержка действующего производства

| Параметр | Значение |
|----------|----------|
| Русское | Поддержка действующего производства |
| English | Production Support |
| Оценка | Самый страшный случай |
| Причина | В серийном производстве произошёл сбой |
| Цель | Предотвратить остановку серийного производства |
| Потери при остановке | Сотни миллионов рублей |
| Что направляется в УПП | Запрос на изготовление КИ |
| Какое КИ | То, которое не поступает на конвейер по форс-мажорной причине |
| Приоритет | Высший приоритет |
| Инициатор | Неизвестно (единственный запрос, где инициатор не проект) |
| Срочность | Страх персонала перед увольнением |
| Частота | Очень большая редкость |
| Для ERP | Сейчас не важно |
