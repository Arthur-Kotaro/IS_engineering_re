# Проработка и техпроверка

> Источник: ЧАСТЬ 16 полной документации.

## Проработка состава

| Параметр | Значение |
|----------|----------|
| Регламент | Не регламентируется |
| Критерий | Документация должна быть правильной, полной и зрелой |
| Последствие ошибки | Прототип не соберётся или будет непригоден |
| Количество итераций | Зависит от профессионализма составителя и сложности конструкции |
| Система | ЭДО |
| Формат | Служебная записка с приложенным составом |
| При отказе | Резолюция с замечаниями |
| Дополнительно | Прямое общение любыми способами |
| Группа проработчиков | Входит в КТО |

## Технологическая проверка

| Параметр | Значение |
|----------|----------|
| Когда | Параллельно с проработкой |
| Критерий | Техвозможность изготовления |
| Если КД нет | Запрос недостающей КД |
| Если техневозможность | Исключение КИ из состава; размещение на внешнем поставщике (аутсорс); другие способы |
| Библиотека техпроцессов | Есть, но ограниченно применима (прототипы — уникальные разовые работы) |
| Кто решает о серийном производстве | прото-РП + технолог |
