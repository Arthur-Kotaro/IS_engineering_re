## Функции участков (подробно)

### Участок замеров

| Параметр | Значение |
|----------|----------|
| Русское | Участок замеров |
| English | Measurement Area |
| Что расположено | Парк контрольно-измерительных машин (КИМ) |
| Что делает | Точные замеры |
| Результат | Карты замеров |
| Кому передаёт | КТО (технологу) |
| Что замеряет | Детали и оснастку (если требуется) |

### Бюро контроля качества сборки

| Параметр | Значение |
|----------|----------|
| Русское | Бюро контроля качества сборки |
| English | Assembly Quality Control Bureau |
| Что контролирует | Сборку |
| Особенно | ДВС и автомобили |

### Инструментальный участок / Кладовая оснастки

| Параметр | Значение |
|----------|----------|
| English | Tool Store |
| Тип | Одно подразделение |
| Что хранит | Режущий инструмент |
| Кому выдаёт | Мастерам |
| Подчинение | Предположительно отделу обеспечения производства |
| С серийным производством | Не взаимодействует |
| Собственное производство | Нет |
| Расположение | Отдельное небольшое помещение вне цеха |

### Участок механической обработки по дереву

| Что изготавливает | English |
|-------------------|---------|
| Формовочные короба | Molding Boxes |
| Матрицы для листового металла | Sheet Metal Dies |
| Оснастка из сибатула | Sibatul Tooling |
| Сварочные кондукторы | Welding Fixtures |

- **Сибатул** — материал, среднее между деревом и пластмассой. Не меняет размеры со временем и под действием влаги.
- **Формовочные короба** — работают по принципу ведёрка для куличиков. Придают нужную форму песчаным стержням.
- **Сварочный кондуктор** — изготовленный из дерева ложемент, на котором размещают заготовки для удобства и точности позиционирования при сварке. Пример: для СВОГ.

### Участок разметки заготовок

| Параметр | Значение |
|----------|----------|
| Что делает | Покрывают отливку краской, специальный механизм царапает краску, точная разметка поверхностей под мехобработку |
| Когда не нужна | Если обработка на ЧПУ |
| Когда нужна | В основном для не-ЧПУ. Бывают иные случаи |
