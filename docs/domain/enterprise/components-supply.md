# Обеспечение КИ

> Источник: ЧАСТЬ 9 полной документации.

## Три раздела состава КИ

| № | Раздел | English |
|---|--------|---------|
| 1 | Покупные | Purchased Components |
| 2 | Серийные | Serial Components |
| 3 | Производимые | Manufactured Components |

## Серийные КИ

| Параметр | Значение |
|----------|----------|
| Откуда | Серийные склады |
| Кто привозит | Бюро серийных КИ (СТС) |
| Документы | Накладные |
| Особенность | Ручные/точечные перемещения вопреки автоматизированной системе |
| Зачем | Для особых нужд |
| Фиксация | В момент поступления на склад УПП |
| Хранение | Склад УПП |

## Покупные КИ

| Параметр | Значение |
|----------|----------|
| Откуда | Поставщики |
| Кто заказывает | Бюро оригинальных КИ (СТС) |
| При наличии рамочного договора | Бюро направляет PR поставщику |
| Ответ поставщика | Неподписанный PO (цены, сроки, способ поставки) |
| Согласование PO | прото-РП + экономист УПП + главный инженер + экономист проекта |
| Подписание | Закупщик + поставщик |
| Оплата | Главная бухгалтерия |
| Изготовление | Поставщик |
| Передача | Логистам СТС |
| Проверка | Логисты СТС |
| Письмо | Письмо на соответствие |
| Перемещение | На склад УПП |

## Производимые КИ

| Параметр | Значение |
|----------|----------|
| Кто изготавливает | Цеха УПП |
| Кто разрабатывает ТД | Бюро сборки (КТО) |
| Контроль | Выходной контроль (отдел качества УПП) |
| После контроля | На склад УПП |
| Перемещения | Логисты УПП (бюро внутренней логистики) |
