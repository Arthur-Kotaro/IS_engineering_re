# Серийное производство

> Источник: ЧАСТЬ 10 + ЧАСТЬ 2.6 полной документации.

## Общее

| Параметр | Значение |
|----------|----------|
| Роль | Внешнее для УПП. Привлекается для спец. операций |
| Когда привлекается | Нужны исключительные возможности оборудования |
| Виды работ | Изготовление отливок; нанесение спец. покрытий; быстрая обработка больших партий заготовок на автоматизированных линиях с фасонным инструментом |
| Кто решает | прото-РП + технолог |
| Кто направляет наряд-заказ | Экономист УПП |
| Кто договаривается | прото-РП ↔ РП серийного производства |
| Кто перемещает | Логисты УПП |
| Документы | Накладные |
| Акт | прото-РП + экономист УПП |
| Для ERP | Почти не касается |

## Процесс с кокилем

| Параметр | Значение |
|----------|----------|
| Частота | Очень редко |
| Когда | При изготовлении деталей ДВС |
| Управляет | прото-РП вручную |
| Шаги | 1. Договорённость; 2. Забрать кокиль; 3. Перевезти в УПП; 4. Заменить элементы (вставки, полуформы); 5. Изменить геометрию мастикой; 6. Перевезти в металлургическое производство; 7. Изготовить партию отливок; 8. Вернуть кокиль; 9. Восстановить; 10. Вернуть в серийное производство; 11. Забрать отливки в УПП |
| Оформление | Наряд-заказ |
| Источник кокиля | «Могут купить у цыган. Наверное.» |
