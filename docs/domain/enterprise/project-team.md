# Команда проекта

> Источник: ЧАСТЬ 4 полной документации.

## Роли и зоны ответственности

| Роль | Русский | English | Зона ответственности |
|------|---------|---------|----------------------|
| Глава команды | Главный инженер | Chief Engineer | Общее руководство. 1–3 проекта лично. До 20 одновременно |
| Сквозной координатор | Руководитель проекта по прототипам (прото-РП) | Prototype Project Manager | От запроса до передачи. Информацию вытягивает сам |
| Руководители | Руководители проектов | Project Managers | Свои направления |
| Финансы | Экономист проекта | Project Economist | Согласование ТЗ, PO. Учёт себестоимости носителя для мула |
| Мастерграфик | Инженер по планированию продукта | Product Planning Engineer | Держатель Мастерграфика |
| Валидация | Специалист по валидации | Validation Specialist | План валидации |
| Качество | Инженер по качеству | Quality Engineer | Чеклисты, вехи, мнения |

## Особенности команды

| Параметр | Значение |
|----------|----------|
| Команда ведёт | 1 проект |
| Члены команды | Могут участвовать в нескольких проектах |
| Практика | Команды под одним главным инженером часто совпадают по составу |
| Юрист в проекте | Нет |
| Где юрист | ДПЗ |
| Специалист по рискам | Нет. Заменяет инженер по качеству |
| Инженер по качеству | Активно участвует. Член команды или нет — не уверен |

## Инженер по качеству

| Параметр | Значение |
|----------|----------|
| Отвечает за | Качество проектной работы, не продукта |
| Инструмент | Коллекция чеклистов по типологиям проектов |
| Типология | Определяет вехи и интервалы между ними |
| Обязанность членов команды | Предоставлять мнения на веху |
| Чеклист | Определяет, кто и на какую веху даёт мнение |
| Участие | Активно в периоды перед прохождением вех |
