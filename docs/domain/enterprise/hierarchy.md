# Сквозная иерархия

> Источник: ЧАСТЬ 1 полной документации.

| Уровень | Русский | English |
|---------|---------|---------|
| 1 | Служба | Division |
| 2 | Дирекция | Directorate |
| 3 | Управление | Department |
| 4 | Отдел | Section |
| 4 | Цех | Shop |
| 5 | Бюро | Bureau |
| 5 | Группа | Group |
| 5 | Производственный участок цеха | Production Area |
| 6 | Исполнитель | Engineer / Operator |

**Важно:**
- Мастер — должность, не подразделение.
- Производственный участок — подразделение.
- Группа — подразделение (например, группа проработчиков составов).
