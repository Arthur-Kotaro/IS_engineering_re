# Справочник предметной области: ВАЗ / УПП

> **Статус:** это справочник предметной области автомобильного
> инжиниринга (ВАЗ, г. Тольятти, УПП). **Не является ТЗ.**
> Используется как источник примеров при проектировании платформы
> и как возможный источник бизнес-логики на финальной фазе.
> Реализация — **не гарантирована**.
>
> Источник: знания руководителя проекта по прототипам (прото-РП)
> о предприятии ВАЗ. Без упрощений. Без выжимок. Без потерь.
