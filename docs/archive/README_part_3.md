| Параметр | Значение |
|----------|----------|

| Что хранит | Режущий инструмент |

### 23.4. Участок механической обработки по дереву

| Что изготавливает | English |
|-------------------|---------|
| Формовочные короба | Molding Boxes |
| Матрицы для листового металла | Sheet Metal Dies |
| Оснастка из сибатула | Sibatul Tooling |
| Сварочные кондукторы | Welding Fixtures |

- Сибатул — материал, среднее между деревом и пластмассой. Не меняет размеры со временем и под действием влаги.
- Формовочные короба — работают по принципу ведёрка для куличиков. Придают нужную форму песчаным стержням.
- Сварочный кондуктор — изготовленный из дерева ложемент, на котором размещают заготовки для удобства и точности позиционирования при сварке. Пример: для СВОГ.

### 23.5. Участок разметки заготовок

| Параметр | Значение |
|----------|----------|
| Что делает | Покрывают отливку краской, специальный механизм царапает краску, точная разметка поверхностей под мехобработку |
| Когда не нужна | Если обработка на ЧПУ |
| Когда нужна | В основном для не-ЧПУ. Бывают иные случаи |

## ЧАСТЬ 26. КЛЮЧЕВЫЕ ПРАВИЛА

1. До ТЗ — ничего не запускается.
2. Проработка и техпроверка — параллельно.
3. ТЗ — триггер.
4. ТЗ согласовывают: экономист проекта + главный инженер.
5. PO согласовывают: прото-РП + экономист УПП + главный инженер + экономист проекта.
6. Наряд-заказ в серийное производство направляет экономист УПП.
7. Акт выполненных работ (серийное производство) подписывают: прото-РП + экономист УПП.
8. Акт об изготовлении подписывают: контролёр, технолог, мастер, начальник цеха.
9. Акт приёма/передачи подписывают: логист УПП + представитель заказчика.
10. Ретрофит: УПП получает образец, переоборудует, отдаёт.
11. Ретрофит: лишние КИ — утилизация по умолчанию.
12. BUK — категория, в запросе одна из трёх подкатегорий.
13. Body/Unit: решают технолог + прото-РП, согласуют с заказчиком (email).
14. Kit: комплектует склад, документы — накладная + акт.
15. Доработка: ДЗК, 1–3 КИ, изменение геометрии/размеров.
16. Поддержка производства: высший приоритет, редкость.
17. План валидации: один раз, меняется при форс-мажорах, согласует главный инженер.
18. Невостребованные КИ: никак не учитываются.
19. Серийное производство: почти не касается ERP.
20. Бюджет: отдельная тема, не для ERP.
21. Мастерграфик: отдельная тема, первый бизнес-сервис.
22. прото-РП: вытягивает информацию сам.
23. Отчётность: раз в месяц.
24. УПП — управление (Department), не дирекция.
25. AVES проводится только в фазе Industrialization.
26. Склад комплектует комплект КИ по комплектовочной ведомости и передаёт мастеру.
27. ДПЗ не участвует в прототипах.
28. «Внешнего подразделения закупок» не существует.
29. Мул — это шестой тип запроса.
30. Инициатор мула — проект.
31. Модель-носитель выбирает проект, окончательно — главный инженер.
32. Передача носителя — по акту.
33. Оплата себестоимости носителя — через экономиста проекта.
34. После изготовления мул передаётся в подразделение испытаний.
35. После испытаний мул — утилизация.
36. Опытные КИ — утилизация.
37. Акт на переоборудование — как при ретрофите.
38. Документ мула — только ТЗ.
39. Мул фигурирует в плане валидации.
40. Количество мулов — от 4 до 10.
41. Ретрофит ≠ мул.
42. В автомобильном проекте 2–3 лота.
43. Первый лот — почти всегда мулы.
44. Количество мулов — 4–10 на первый лот (и на проект).
45. Себестоимость носителя — через экономиста проекта.
46. Кузов серийного автомобиля-носителя, как правило, тоже претерпевает изменения.
47. Мул может быть переоборудован повторно — это норма.
48. Повторное переоборудование мула = ретрофит.
