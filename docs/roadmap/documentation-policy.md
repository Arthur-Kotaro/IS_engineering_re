# Правило ведения документации

**Версия:** 6.1
**Дата обновления:** 2026-11-16

## Разбиение спиралей на фазы и блоки
- Каждый блок = один диалог.
- Timestamp при обновлении.
- `progress.md` — живой документ.

## Требования к разработке
1. **C/C++ строго в стиле Allman.**
2. **Файл > 450 строк → делим.**
3. Python — PEP 8.
4. Одна порция = одна проверка.
5. Новые файлы и перезаписи — `cat > файл <<'EOF'`.
6. Точечные правки — вручную.
7. `sed`, `awk` — не использовать.

## Формат обновления
- Полная перезапись — `cat >`.
- Точечные правки — вручную.
- Timestamp в шапке.
