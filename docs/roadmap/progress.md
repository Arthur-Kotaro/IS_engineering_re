### Спираль 6.6. Roles & Positions & Departments (в работе)
Цель: переработка модели ролей и структуры подразделений.
- Разделение `positions` (должности) и `roles` (разрешённые роли).
- Новая модель `departments` (6 уровней, UUID, EN/RU).
- Убрать `head_id`, `dept_code` (строку), `projects` у пользователя.
- Переписать модель ролей: роль — производная от должности и подразделения.
- Project Service: справочник `project_roles` + `project_members.role_code`.
- Navigation Service: три таблицы плиток (по ролям, по должностям, универсальные).
- SQL-схема БД создана на desktop PC.
- Переписаны модели User Service.
- Осталось: Auth Service, Project Service, Navigation Service, запуск.

- **Клиент (порция 2026-10-12):**
  - Компонентный подход к рендерингу — библиотека `BaseWidgets 1.0`
    (`SearchableListSingle`, `SearchableListMulti`, `SearchableSelect`).
  - Семантический слой цветов `action*` в `Colors.qml` (ADR 0012).
  - Кнопка «Назад» в `TabContent.qml` с `context.can_go_back` (ADR 0011).
  - Скроллбар вкладки через `Flickable` + `contentHeightChanged` (ADR 0013).
  - Ограничение ширины полей ввода 800 px, инфографика — без ограничения (ADR 0013).
  - `Qt6::QuickShapes` подключён как зависимость клиента.

## Отменено

- **Модель `owner/manager/editor/viewer`** в Project Service — **выдуманная**, не соответствует реальности. Заменена на `project_roles` справочник + реальные проектные роли.
- **`head_id` у пользователя** — не нужен. Иерархия — через `departments.parent_dept_id`.
- **Композиция `direct OR subordinate OR delegated`** — не реализована, не нужна.
- **Роль X («Директор по менеджменту проектов»)** как артефакт — заменена на роль `project_management_director`.
- **`upp_head`** — дубликат `proto_production_head`, удалён.
