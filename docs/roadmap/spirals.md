## Git-история

**Внимание:** Спирали 3, 4, 5 и часть 6.5 не имели отдельных коммитов.
Всё улетело в коммиты `10c9012` (основной репо) и `1714112` (USER_service) в конце Спирали 6.5.

**Правило на будущее:** коммит после каждой крупной порции работы.
Минимум — после каждого блока, который проверен и работает.

## Отложено

- **Логирование.** Единая система логов — не внедрена.
- **Observability.** Метрики Prometheus, трейсинг, Grafana.
- **CI/CD.** Пайплайны, автосборка.
- **Alembic.** Миграции через `create_all`.
- **Событийная шина.** Redis pub/sub для `user.events`. Полноценная шина (NATS) — позже.
- **Outbox.** Не внедрён.
- **Мультитенантность.** Не рассматривалась.
- **Локализация.** Русский захардкожен.
- **Streaming файлов.** Nginx настроен, но MG Service ещё не реализован.

## Незакрытые задачи Спирали 5

- Row-select в `Table` — генератор клиента не отправляет событие.
- Валидация на сервере — заглушка.
- Кнопка «Назад» в UI клиента → `POST /workflow/back`.
- Закрытие вкладки → `POST /workflow/close`.
- Интеграция `ImpersonateWindow` + `DelegatedWindow` с C++ (QML созданы).
- Проверка событий `user.deleted` / `user.blocked` end-to-end.

## Триггеры пересмотра

- Пользователей > 500 → пересмотр кэша nginx, кэш прав, нагрузка Auth.
- Репликация БД → отдельная спираль.
- Несколько инстансов Navigation → переход на Postgres.
- Streaming больших файлов → настройка nginx.
