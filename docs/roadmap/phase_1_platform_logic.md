## 2. Телефонный справочник

Нужно добавить справочник пользователей. В navigation service
добавить универсальные плитки (для всех пользователей):
«Справочник пользователей», «Техническая поддержка»
(поддержку реализуем позже).

Справочник состоит из вертикальной левой панели и основной области.

### Левая панель

Используется для поиска пользователя и содержит:
- 3 поля ввода ФИО;
- выпадающий список для выбора должности;
- 2 поля ввода: кода подразделения пользователя и названия подразделения;
- кнопку «Поиск».

### Основная область

- Отображается в области вертикальной прокрутки. Левая зафиксирована.
- Отражает иерархическую структуру подразделений в виде выпадающих
  списков, которые можно сворачивать или разворачивать по нажатию
  на значок «+» или «-».
- При сворачивании подразделения перестают отображаться вложенные
  подразделения и визитки.
- Ниже строки с названием подразделения указывается визитка
  (описание профиля) руководителя подразделения.
- При разворачивании списка наиболее глубокой вложенности
  отображаются визитки пользователей. Например, при разворачивании
  списка членов бюро показываются визитки начальника бюро и
  сотрудников бюро.

### Поведение

- Пользователь может просматривать структуру и визитки пользователей
  в основной области.
- Если пользователь воспользовался поиском из левой панели и поиск
  нашёл пользователей, соответствующих запросу, в основной области
  автоматически сворачиваются все подразделения, за исключением тех,
  в которых числятся найденные пользователи.
