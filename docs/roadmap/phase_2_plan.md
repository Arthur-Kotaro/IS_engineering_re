# Фаза 2. План разработки

> Источник: первый присланный файл.

## Цель

Расширение платформы.

## Что реализовать

1. **МС бюджетирования проектов.** Базовый универсальный
   микросервис теперь позволяет аккумулировать затраты и передавать
   в сервис бюджетирования проектов.
2. **МС учёта рабочего времени.** Отпуска, выходные, больничные,
   неоплачиваемое отсутствие.
3. **МС моделирования бизнес-процессов и спец. клиент.**
   Бизнес-аналитик через GUI (предварительно использовать
   существующий механизм создания административной структуры)
   формирует модель взаимодействий, задавая роли для user service,
   RASIC, типовые маршруты для ЭДО. Визуализация и всепроникающее
   влияние на бизнес-сервисы (включая типологии проектов) и ЭДО.
4. **МС ЭДО**, позволяющая создавать служебные записки в двух
   режимах: ручном и по шаблону.
5. **Привязать задачи МС МГ к сервису ЭДО:** через МГ можно будет
   просматривать маршруты СЗ ЭДО через контекстное меню задачи.
6. **Оркестрация UI Composer service и Navigation service.**

## Примечания

МГ МС позволяет просматривать:
1. отчёт о статусе работ по проекту;
2. ЛГ и согласования СЗ.

Система уведомлений собирает информацию о:
1. включении пользователя в маршрут ЭДО;
2. наличии готовых к согласованию СЗ.
