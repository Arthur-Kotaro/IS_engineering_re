# Стратегия проекта

## Смена парадигмы

Изначально проект задумывался как **ERP-система для автомобильного
инжинирингового предприятия** (по образцу ВАЗ/УПП, где автор работал
руководителем проекта по прототипам).

Со временем стало ясно: это **очень узкий рынок**, шансы на
коммерческий успех невелики. Стратегия скорректирована.

## Новая стратегия

**Engineering:re — это платформа**, а не отраслевое решение.

Акцент — не на реализации бизнес-логики конкретного предприятия,
а на выстраивании **гибкой и универсальной системы**, которая
может быть адаптирована под произвольную инжиниринговую компанию.

Бизнес-логика автомобильного инжиниринга (ВАЗ/УПП) —
**в самом конце. Если вообще будет.**

## Базовый универсальный бизнес-МС

Ключевое нововведение Фазы 1.

**Было:** уникальные микросервисы под каждое подразделение,
обслуживающие специфические потребности.

**Стало:** **базовый универсальный бизнес-микросервис** (бизнес-МС),
решающий типовые задачи, общие для всех подразделений предприятия.
Без специализации на конкретной отрасли.

При этом в системе **умышленно** разворачивается несколько
совершенно одинаковых с точки зрения программного кода экземпляров
такого сервиса. В этом есть смысл:

- каждый экземпляр может быть доработан и дополнен специфическим
  функционалом **независимо** от других;
- специализация может создаваться **«на лету»** — после развёртывания
  системы и выхода в эксплуатацию;
- Discovery service находит экземпляры и маршрутизирует запросы.

## Что это значит для документации

| Уровень | Что это | Где |
|---|---|---|
| Платформа | Универсальные механизмы: workflow, UI Composer, Navigation, базовый бизнес-МС, discovery, уведомления, оркестрация | `roadmap/phase_*.md`, `architecture/`, `contracts/`, `adr/` |
| Домен ВАЗ/УПП | Справочник предметной области автомобильного инжиниринга | `domain/enterprise/` |
| Бизнес-логика предприятия | То, что будет реализовываться в конце, если вообще | Возможная Фаза 3. Сейчас не планируется |

## Возможное будущее

**Фаза 3** — реализация бизнес-логики конкретного предприятия
(например, ВАЗ/УПП) поверх платформы.

Вводить её явно в дорожную карту пока не имеет смысла.
Упомянута как возможность.
