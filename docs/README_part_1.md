### 4.1. Особенности команды

| Параметр | Значение |
|----------|----------|
| Команда ведёт | 1 проект |

| Параметр | Значение |
|----------|----------|

### Тип 1. Изготовление прототипа с нуля

| Параметр | Значение |
|----------|----------|

### Тип 2. Ретрофит

| Параметр | Значение |
|----------|----------|
| Русское | Ретрофит |
| English | Retrofit |
| Инициатор | Проект |
| Что прилагается | Состав с минимумом наименований КИ |
| Что в составе | Только те КИ, которые нужно установить |
| Что делает УПП | Получает физический образец для переоборудования |
| Кто передаёт образец | Те, у кого он находится: подразделение, проводившее испытания, либо подразделение, проводившее калибровки |
| Документ приёма | Акт приёма-передачи |
| Что делает УПП дальше | Проводит переоборудование |
| Кому отдаёт | Заказчику работ |
| Что с лишними КИ | По умолчанию — утилизация |
| Если проект запросил сохранить | Остатки на склад или ответственному лицу по накладной |
| Акт на переоборудование | Почти как классическое задание |
| Цель | Замена части КИ |
| Пример | Замена модуля впуска ДВС |
| Преимущество | Не нужно изготавливать новый ДВС |
| Результат | Объект приобретает новые технические характеристики |
| После | Снова испытания |
| Отличие от мула | Ретрофит — переоборудование объекта, ранее изготовленного в УПП и прошедшего испытания |

### Тип 4. Доработка

| Параметр | Значение |
|----------|----------|
| Русское | Запрос на доработку |
| English | Rework Request |
| Инициатор | Проект |
| Что получает УПП | Заготовку |
| Альтернатива | Заказывает серийную деталь |
| Что делает | Вносит изменения в конструкцию |
| Кому передаёт | Заказчику работ |
| Особенность 1 | Вместо ТЗ выпускается доводочное задание (ДЗК) |
| Особенность 2 | Работа над одной-тремя простыми КИ |
| Важно | Не узлами, а именно КИ |
| Особенность 3 | Изготовление не с 0, а доработка существующего изделия |
| ДЗК vs ТЗ | Не отличается от ТЗ. Почти. Будем считать, что не отличается |
| Ограничения по материалам | Вопрос не понят — открыт |
| Отличие от ретрофита | Ретрофит — разборный объект, замена частей. Доработка — изменение геометрии/размеров КИ. Обычно обработка металлов резанием, сварка |

### Тип 6. Мул (MULE)

| Параметр | Значение |
|----------|----------|
| Русское | Мул |
| English | MULE |
| Расшифровка | Знает только Ктулху |
| Что это | Гибрид: серийный автомобиль-носитель + опытные КИ |
| Зачем | Ускорение процесса разработки нового автомобиля |
| Когда применяется | Когда нужно провести длительные испытания уже спроектированных деталей, узлов и систем, а автомобиль ещё не спроектирован целиком и его нельзя изготовить целиком |
| Что выбирают | Наиболее схожую с проектируемой моделью существующую серийную модель |
| Кто выбирает | Проект. Окончательное решение — главный инженер |
| Откуда берут | Забирают из серийного производства |
| Документ передачи носителя | Акт |
| Себестоимость автомобиля-носителя | Учитывается в бюджете проекта. Через экономиста проекта. Сложная схема, сейчас не важна |
| Что направляют в УПП | Запрос на переоборудование серийного автомобиля |
| Что делает УПП | Переоборудует серийный автомобиль, устанавливая на него прототипные детали, узлы |
| Кузов | Как правило, тоже претерпевает изменения |
| Результат | Гибрид (серийный автомобиль-носитель + опытные КИ) |
| Название результата | Мул (MULE) |
| Что дальше | Передают в подразделение, занимающееся испытаниями |
| После испытаний | Утилизация |
| Опытные КИ после испытаний | Утилизация |
| Акт на переоборудование | Так же, как при ретрофите |
| Документ | Только ТЗ |
| Ограничения по количеству | Нет. С точки зрения бюджета — чем меньше, тем лучше. На практике от 4 до 10 |
| Связь с планом валидации | Обязательно фигурирует |
| Название процесса | «Переоборудование серийного автомобиля», «Изготовление мула», изредка «Ретрофит» (не совсем верно) |
| Кто управляет | прото-РП — как и в иных случаях |
| Отличие от ретрофита | Тонкий смысловой оттенок. Ретрофит — переоборудование объекта, ранее изготовленного в УПП и прошедшего испытания. Мул — переоборудование серийного носителя без истории испытаний |
| Может быть переоборудован повторно? | Да. Это норма. Становится объектом ретрофита |
| Место в проекте | Первый лот. Почти всегда |
