# Инженерный клиент User Service

## 📋 Описание

Консольный клиент для тестирования и отладки микросервиса управления пользователями. Позволяет выполнять все основные операции аутентификации и управления пользователями через командную строку.

## 🎯 Назначение

- Тестирование API микросервиса пользователей
- Отладка авторизации и аутентификации
- Проверка работы JWT токенов
- Автоматизация тестирования в CI/CD

## 🛠️ Функциональные возможности

### Основные операции
- ✅ **Логин** - аутентификация пользователя (обычный/администратор)
- ✅ **Проверка срока пароля** - получение информации об истечении пароля
- ✅ **Смена пароля** - изменение пароля авторизованного пользователя
- ✅ **Сброс пароля** - запрос на восстановление доступа
- ✅ **Refresh токен** - обновление пары JWT токенов
- ✅ **Health check** - проверка доступности сервера

### Управление сессией
- 💾 **Сохранение сессии** - запись токенов в JSON файл
- 📂 **Загрузка сессии** - восстановление из файла
- 🚪 **Logout** - завершение сессии

## 📦 Сборка

cd /path/to/CLIENT
mkdir build && cd build
cmake .. -DBUILD_ENGINEERING_CLIENT=ON
make -j$(nproc)

## 🚀 Запуск

Базовый запуск

./EngineeringClient -s localhost -p 8000

## 🚀 Параметры командной строки

Параметр    Описание    Значение по умолчанию
-s,         --server    Адрес сервера localhost
-p,         --port      Порт сервера 8000
-h,         --help      Справка -
-v,         --version   Версия -


### Требования
- CMake 3.16+
- Qt6 (Core, Network)
- C++17 компилятор
- OpenSSL (опционально)

### Команды сборки

cd engineering_client
mkdir build && cd build
cmake .. -DCMAKE_PREFIX_PATH=/path/to/Qt6
make -j$(nproc)
