# Описание подмодуля CLIENT/cmake

## Назначение этой части

Модуль `CLIENT/cmake` отвечает за настройку и конфигурацию сборки клиентского приложения ERP для инжиниринговых компаний, использующего стек Qt/QML. В данном модуле находятся CMake-скрипты, которые обеспечивают правильную компиляцию проекта, управление зависимостями и развертывание на различных платформах.

## Основные компоненты и их ответственность

1. **CodeCoverage.cmake** - Скрипт для настройки сборки с поддержкой покрытия кода тестами.
2. **Config.h.in** - Шаблон заголовочного файла конфигурации, который используется CMake для генерации `Config.h` с необходимыми параметрами компиляции.
3. **DeployLinux.cmake** - Скрипт для развертывания приложения на Linux-системах.
4. **DeployWindows.cmake** - Скрипт для развертывания приложения на Windows-системах.
5. **Findnlohmann_json.cmake** - Модуль поиска библиотеки `nlohmann/json` в системе или внешних директориях.

## Ключевые сущности

1. **Конфигурация сборки**: Управление параметрами компиляции, оптимизациями и флагами.
2. **Зависимости**: Поиск и настройка необходимых библиотек (например, `nlohmann/json`).
3. **Развертывание**: Автоматическое развертывание приложения на различных платформах.

## API эндпоинты

В данном модуле нет прямого описания API-эндпоинтов, так как он предназначен для сборки и конфигурации клиента. Однако, можно предположить, что клиент будет взаимодействовать с бэкендом через определённые API-эндпоинты, которые описаны в других частях документации проекта.

## Зависимости от других частей

1. **CLIENT/common**: Модуль содержит заголовочные и исходные файлы, используемые для взаимодействия с сервисами бэкенда (например, `ApiClient.h`, `AuthService.h`).
2. **API_Gateway**: Клиент будет использовать API Gateway для маршрутизации запросов к различным микросервисам.
3. **USER_service**: Для аутентификации и управления пользователями.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский модуль (CLIENT)**: Модуль `cmake` является подмодулем клиента и предоставляет необходимые скрипты для его сборки и развертывания.
- **Дочерние компоненты**: В данном модуле нет дочерних компонентов, но он взаимодействует с другими частями проекта через CMake.

## Пример использования

Пример использования скриптов из этого модуля может включать выполнение команд сборки и развертывания:

```bash
mkdir build && cd build
cmake ..
make
# Для Linux-развертывания:
cmake -P ../CLIENT/cmake/DeployLinux.cmake
# Для Windows-развертывания:
cmake -P ../CLIENT/cmake/DeployWindows.cmake
```

Этот документ предоставляет общее представление о модуле `CLIENT/cmake` и его роли в сборке и развертывании клиентского приложения ERP для инжиниринговых компаний.
