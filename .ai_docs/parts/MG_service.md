# MG_service: Сервис управления мощностными блоками

## Назначение этой части
MG_service (Mastergraphics Service) является микросервисом, который отвечает за управление данными о типологии мощностных блоков в системе ERP для инжиниринговых компаний. Он предоставляет API для взаимодействия с этими данными и может быть расширен для более сложной логики управления.

## Основные компоненты и их ответственность
- **run.sh**: Скрипт запуска сервиса. Он активирует виртуальное окружение (если оно существует) и запускает приложение на порту 8003 с помощью uvicorn.

## Ключевые сущности
- **power_unit_typology.json**: Файл, содержащий данные о типологии мощностных блоков.
- **typology.json**: Общий файл типологии (возможно, содержит дополнительные или общие данные).

## API эндпоинты
На текущий момент в документации нет явного перечисления всех доступных API эндпоинтов. Однако, исходя из названия сервиса и его назначения, можно предположить, что он может содержать следующие эндпоинты:
- **GET /typology**: Получение данных о типологии мощностных блоков.
- **POST /typology**: Добавление новой записи в типологию мощностных блоков.
- **PUT /typology/{id}**: Обновление существующей записи в типологии мощностных блоков.
- **DELETE /typology/{id}**: Удаление записи из типологии мощностных блоков.

## Зависимости от других частей
MG_service зависит от:
- **PostgreSQL (БД)**: Для хранения данных о типологиях мощностных блоков.
- **API Gateway**: Для маршрутизации запросов к MG_service.

## Взаимодействие с родительскими/дочерними компонентами
MG_service взаимодействует с другими микросервисами и клиентской частью системы через API Gateway:
- **Клиентская часть**: Может запрашивать данные о типологии мощностных блоков для отображения в пользовательском интерфейсе.
- **Другие микросервисы**: Могут использовать данные из MG_service для выполнения своих задач, например, при расчетах или планировании.

## Пример запуска
Для запуска сервиса необходимо выполнить следующую команду в корневом каталоге проекта:
```bash
cd MG_service
./run.sh
```

Этот скрипт активирует виртуальное окружение и запускает FastAPI приложение на порту 8003.
