# Часть: CLIENT/tests/engineering

## Назначение этой части

Компонент `CLIENT/tests/engineering` предназначен для тестирования функциональности инженерного клиента ERP системы. Он включает в себя модульные и интеграционные тесты, которые проверяют работу различных компонентов клиентского приложения, особенно связанных с аутентификацией пользователей и управлением сессиями.

## Основные компоненты и их ответственность

1. **TestEngineeringConsole.cpp**
   - **Ответственность**: Этот файл содержит тест-кейсы для проверки функциональности `EngineeringConsoleUI` и связанных сервисов, таких как аутентификация пользователей.
   - **Ключевые функции**:
     - Тестирование успешного входа пользователя.
     - Проверка обработки ошибок при неверных учетных данных.
     - Проверка механизма проверки срока действия пароля после входа.
     - Тестирование процесса обновления токенов доступа и обновления.

## Ключевые сущности

1. **EngineeringConsoleUITest**
   - Класс для тестирования пользовательского интерфейса инженерного клиента.
2. **AuthService**
   - Сервис аутентификации, который используется для проверки входа пользователя и управления токенами доступа.
3. **MockApiClient**
   - Мок-клиент API, используемый для имитации взаимодействия с серверной частью системы без необходимости подключения к реальному серверу.

## API эндпоинты

Тесты в `TestEngineeringConsole.cpp` используют следующие API эндпоинты:

1. **POST /auth/login**
   - **Описание**: Проверяет успешный вход пользователя с правильными учетными данными.
2. **GET /auth/password-expiry**
   - **Описание**: Проверяет информацию о сроке действия пароля после успешного входа.

## Зависимости от других частей

1. **CLIENT/common/include/userserviceclient/AuthService.h**
   - Сервис аутентификации, используемый в тестах.
2. **CLIENT/tests/utils/MockApiClient.h**
   - Мок-клиент API для имитации взаимодействия с сервером.
3. **CLIENT/tests/utils/TestHelpers.h**
   - Вспомогательные функции и классы для написания тестов.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент**: `CLIENT/tests` — общая папка для всех тестов клиента.
- **Дочерние компоненты**: Нет прямых дочерних компонентов, но файл `TestEngineeringConsole.cpp` использует различные вспомогательные классы и функции из других модулей проекта.

Этот документ описывает структуру и назначение тестовых сценариев для инженерного клиента ERP системы. Он помогает разработчикам понять, какие аспекты функциональности проверяются в тестах и как они взаимодействуют с другими частями проекта.
