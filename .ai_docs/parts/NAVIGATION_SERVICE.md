# NAVIGATION_SERVICE

## Назначение этой части

**Navigation Service** является микросервисом, который предоставляет функциональность для управления и отображения навигационных плиток (tiles) в пользовательском интерфейсе ERP системы. Он позволяет динамически настраивать доступные действия и информацию для различных ролей пользователей, а также поддерживает интеграцию с другими сервисами через механизмы бейджей (badges), которые могут отображать актуальные данные.

## Основные компоненты и их ответственность

1. **API**
   - **app/api/v1/navigation.py**: Содержит определения эндпоинтов для взаимодействия с навигационными плитками, включая получение данных для дашборда и административные операции по созданию новых плиток.
   
2. **Миграции**
   - **app/migrations/add_badge_columns.sql**: Скрипт миграции базы данных для добавления колонок `badge_enabled` и `badge_endpoint` в таблицу `tiles`.

3. **База данных**
   - **navigation.db**: Локальная SQLite база данных, используемая для хранения информации о навигационных плитках.
   - **app/database.py**: Настройки подключения к базе данных и создание сессий.

4. **Модели**
   - **app/models/tile.py**: Определение модели `Tile` для работы с таблицей `tiles` в базе данных, содержащей информацию о навигационных плитках.

5. **Основной модуль приложения**
   - **app/main.py**: Основной файл приложения, который инициализирует FastAPI приложение, подключает маршруты API и настраивает события запуска/остановки сервиса.
   
6. **Скрипты запуска**
   - **run.sh**: Скрипт для запуска Navigation Service с использованием uvicorn.

## Ключевые сущности

1. **Tile (Плитка)**
   - Описывает элемент интерфейса, который может быть отображен на дашборде пользователя.
   - Атрибуты:
     - `role`: Роль пользователя, для которой доступна плитка.
     - `tile_id`: Уникальный идентификатор плитки.
     - `label`: Название или метка плитки.
     - `endpoint`: URL-адрес, по которому будет перенаправлен пользователь при клике на плитку.
     - `method`: HTTP метод для запроса к указанному endpoint (по умолчанию GET).
     - `icon`: Иконка, ассоциированная с плиткой.
     - `is_active`: Флаг активности плитки.
     - `sort_order`: Порядок отображения плиток.
     - `badge_enabled`: Флаг, указывающий на необходимость отображения бейджа с количеством.
     - `badge_endpoint`: URL-адрес для получения данных для бейджа.

## API эндпоинты

1. **GET /api/v1/navigation/dashboard**
   - **Описание**: Возвращает данные для дашборда пользователя, включая список доступных плиток и их текущие значения бейджей.
   - **Параметры запроса**:
     - `Authorization`: Токен авторизации пользователя.
   - **Ответ**:
     ```json
     {
       "tiles": [
         {
           "id": "tile1",
           "label": "Задачи",
           "endpoint": "/tasks",
           "method": "GET",
           "icon": "task_icon.png",
           "badge_count": 5
         }
       ],
       "user_roles": ["admin", "engineer"]
     }
     ```

2. **POST /api/v1/navigation/tiles**
   - **Описание**: Создает новую навигационную плитку.
   - **Параметры запроса**:
     - `Authorization`: Токен авторизации пользователя с правами администратора.
     - `tile_data`: JSON-объект с данными о новой плитке.
   - **Ответ**:
     ```json
     {
       "message": "Tile created",
       "tile_id": "new_tile"
     }
     ```

## Зависимости от других частей

1. **USER_service**
   - Используется для получения ролей пользователя по токену авторизации.
   
2. **Другие микросервисы (например, PJP_SERVICE)**
   - Для получения данных для бейджей, если `badge_enabled` установлено в `true`.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - **API Gateway**: Обрабатывает входящие запросы и перенаправляет их к Navigation Service по соответствующему маршруту.
  
- **Дочерние компоненты**:
  - **Клиентская часть ERP системы (Qt/QML)**: Получает данные от Navigation Service для динамического формирования интерфейса пользователя.
