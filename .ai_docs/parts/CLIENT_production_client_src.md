# Часть проекта: CLIENT/production_client/src

## Назначение этой части

Часть `CLIENT/production_client/src` является реализацией клиентского приложения ERP для инжиниринговых компаний, написанного на Qt/QML. Она отвечает за взаимодействие с пользователем и управление бизнес-логикой клиента.

## Основные компоненты и их ответственность

### Компонент `core`
Этот компонент содержит основные классы, обеспечивающие функциональность ядра приложения:
- **AppCore**: Ядро приложения, отвечающее за его инициализацию.
- **CacheManager**: Управляет кэшированием данных.
- **ConfigManager**: Обеспечивает управление конфигурационными параметрами.

### Компонент `qml_bridge`
Этот компонент предоставляет мост между C++ и QML, позволяя взаимодействовать с бизнес-логикой из пользовательского интерфейса:
- **AuthBridge**: Обеспечивает функциональность аутентификации.
- **MainWindowBridge**: Управляет данными пользователя и проектами, отображаемыми в основном окне приложения.
- **NotificationBridge**: Отвечает за уведомления.

## Ключевые сущности

1. **AppCore**: Ядро приложения, которое управляет его жизненным циклом.
2. **CacheManager**: Обеспечивает кэширование данных для повышения производительности.
3. **ConfigManager**: Хранит и предоставляет конфигурационные параметры (например, адрес сервера).
4. **AuthBridge**: Мост между QML и сервисом аутентификации.
5. **MainWindowBridge**: Мост между QML и бизнес-логикой главного окна приложения.
6. **NotificationBridge**: Мост для управления уведомлениями.

## API эндпоинты

В данной части проекта нет прямого определения API эндпоинтов, так как они реализованы на стороне сервера (бэкенд). Однако, клиент взаимодействует с следующими эндпоинтами через `MainWindowBridge`:
- **GET /api/v1/navigation/dashboard**: Загрузка тайлов для дашборда.

## Зависимости от других частей

Клиентская часть зависит от бэкенда (API Gateway и микросервисов) для выполнения операций аутентификации, получения данных пользователя и проектов. Также она использует библиотеку `userserviceclient` для взаимодействия с сервисом пользователей.

## Взаимодействие с родительскими/дочерними компонентами

### Родительские компоненты
- **CLIENT**: Корневой каталог клиента, который содержит различные подкаталоги и файлы для сборки и запуска приложения.

### Дочерние компоненты
- **core**: Содержит основные классы ядра приложения.
- **qml_bridge**: Обеспечивает взаимодействие между C++ и QML.

Эта часть проекта является ключевой для обеспечения функциональности клиента ERP, включая аутентификацию пользователей, управление данными пользователя и взаимодействие с серверной частью системы.
