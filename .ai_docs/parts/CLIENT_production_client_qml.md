# Документация по CLIENT/production_client/qml

## 1. Назначение этой части

Часть `CLIENT/production_client/qml` проекта отвечает за графический интерфейс пользователя (GUI) клиентской части ERP-системы для инжиниринговых компаний. Она реализована с использованием языка QML и фреймворка QtQuick, что обеспечивает кросс-платформенность и высокую производительность пользовательского интерфейса.

## 2. Основные компоненты и их ответственность

### Компоненты
1. **components/** - содержит повторно используемые UI компоненты.
   - `LoadingSpinner.qml` - индикатор загрузки данных.
   - `MastergraphStatusCard.qml` - карточка статуса mastergraph.
   - `OfflineIndicator.qml` - индикатор оффлайн режима.
   - `PasswordExpiryWarning.qml` - предупреждение о сроке действия пароля.
   - `ProjectRolesList.qml` - список ролей проектов.
   - `TabContent.qml` - содержимое вкладки с возможностью загрузки данных через API.
   - `ToastNotification.qml` - уведомления пользователю.
   - `TopBar.qml` - верхняя панель интерфейса с информацией о пользователе и кнопками управления.
   - `UserInfoPanel.qml` - панель информации о пользователе.
   - `WidgetLoader.qml` - загрузчик виджетов.

2. **delegates/** - содержит делегаты для отображения элементов в списках и представлениях.
   - `MastergraphDelegate.qml`, `ProjectDelegate.qml`, `RoleDelegate.qml` - делегаты для различных списков.

3. **dialogs/** - диалоговые окна приложения.
   - `ChangePasswordDialog.qml` - диалог смены пароля.
   - `ConfirmDialog.qml` - диалог подтверждения действия.
   - `ErrorDialog.qml` - диалог отображения ошибок.
   - `UpdateNotification.qml` - уведомление об обновлениях.

4. **styles/** - стили и темы приложения.
   - `AppStyle.qml` - глобальные стили приложения.
   - `Button.qml` - стиль кнопок.
   - `Colors.qml` - цветовые схемы для светлой и темной тем.
   - `Typography.qml` - типографические настройки.

5. **utils/** - утилитные модули.
   - `DateUtils.qml` - вспомогательные функции для работы с датами.
   - `StringUtils.qml` - вспомогательные функции для строк.
   - `Validators.qml` - валидаторы данных.

6. **views/** - представления приложения.
   - `DashboardView.qml`, `MastergraphView.qml`, `ProjectsView.qml`, `SettingsView.qml` - различные экраны приложения.

7. **windows/** - окна приложения.
   - `AuthWindow.qml` - окно авторизации.
   - `MainWindow.qml` - главное окно приложения после входа пользователя.
   - `SplashScreen.qml` - экран загрузки приложения.

8. **main.qml** - основной файл QML, который запускает приложение и управляет переходами между окнами.

9. **qmldir** - файл описания модуля QML.

10. **ThemeManager.qml** - менеджер тем для переключения светлой и темной темы.

## 3. Ключевые сущности

- **Тема приложения**: управление светлой и темной темами через `Colors.qml` и `ThemeManager.qml`.
- **Авторизация**: окно авторизации (`AuthWindow.qml`) и обработка событий входа пользователя.
- **Основное окно**: главное окно после успешного входа (`MainWindow.qml`), которое включает верхнюю панель, табы с различными представлениями и управление темой приложения.
- **Управление данными**: загрузка данных через API в компоненте `TabContent.qml`.
- **Валидация данных**: валидаторы для полей формы входа (`Validators.qml`).

## 4. API эндпоинты

Для взаимодействия с серверной частью приложения используются следующие API эндпоинты:
- Авторизация пользователя: `POST /api/auth/login`
- Получение данных для вкладок: `GET /api/data/tab/{endpoint}`
- Обновление пароля: `PUT /api/user/password`

## 5. Зависимости от других частей

- **API Gateway**: используется для маршрутизации запросов к различным микросервисам.
- **USER_service**: предоставляет данные о пользователях и управление авторизацией.
- **Другие микросервисы**: предоставляют специфические данные для различных вкладок приложения.

## 6. Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `main.qml` управляет переходами между окнами (`AuthWindow.qml`, `MainWindow.qml`) и запускает приложение.
  
- **Дочерние компоненты**:
  - Внутри `MainWindow.qml` используются различные представления (`views/`), компоненты (`components/`), диалоги (`dialogs/`) и делегаты (`delegates/`).
  - Компонент `ThemeManager.qml` взаимодействует с `Colors.qml` для переключения тем.
  - Компонент `TabContent.qml` загружает данные через API и отображает их в интерфейсе.

## Заключение

Часть `CLIENT/production_client/qml` проекта обеспечивает функциональный и удобный пользовательский интерфейс для ERP-системы инжиниринговых компаний. Она использует современные технологии Qt/QML, что позволяет создавать высокопроизводительные и кросс-платформенные приложения.
