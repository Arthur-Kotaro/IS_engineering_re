# CLIENT/production_client

## Назначение этой части

Модуль `production_client` представляет собой клиентское приложение для инжиниринговых компаний, разработанное с использованием Qt/QML. Это основной интерфейс взаимодействия пользователей с системой ERP (Enterprise Resource Planning), предоставляя им доступ к различным функциям и данным проектов, задач, ресурсов и других важных аспектов управления.

## Основные компоненты и их ответственность

1. **QML файлы**
   - `qml/main.qml`: Основной QML-файл приложения, который определяет структуру окна приложения и управляет переходами между различными экранами (например, аутентификация и основное окно).
   - Компоненты: Различные компоненты для отображения информации о проектах, задачах, пользователях и других данных.
     - `qml/components/`: Содержит общие компоненты, такие как панели загрузки, индикаторы состояния, уведомления и т.д.
     - `qml/delegates/`: Делегаты для отображения элементов списков (например, проекты, роли).
     - `qml/dialogs/`: Диалоговые окна для взаимодействия с пользователем (например, изменение пароля, подтверждение действий).
     - `qml/styles/`: Определения стилей и тем оформления приложения.
     - `qml/utils/`: Утилиты для работы с данными (например, форматирование дат, валидация строк).
     - `qml/views/`: Представления различных экранов приложения (например, дашборд, графики проектов).

2. **C++ файлы**
   - `main.cpp`: Точка входа для приложения на C++. Инициализирует QML движок и устанавливает соединение с сервисом аутентификации.
   - `src/qml_bridge/`: Содержит мосты между C++ и QML, обеспечивающие взаимодействие между ними (например, авторизация, управление окном).
     - `AuthBridge.cpp` и `MainWindowBridge.cpp`: Обеспечивают связь между логикой аутентификации и основного окна приложения с соответствующими QML компонентами.
   - `src/core/`: Ядро приложения, содержащее менеджеры конфигураций и кэша.
     - `AppCore.cpp`, `ConfigManager.cpp`, `CacheManager.cpp`: Управление конфигурацией приложения и кэшированием данных.

3. **Конфигурационные файлы**
   - `config/default_config.json`: Основной JSON-конфигурационный файл для настройки параметров приложения.
   - `config/logging_config.ini`: Конфигурация логирования приложения.

## Ключевые сущности

1. **Пользователи**: Управление учетными записями пользователей, аутентификацией и авторизацией.
2. **Проекты**: Отображение списка проектов, управление задачами внутри проекта.
3. **Данные пользователя**: Информация о текущем пользователе, его роли и правах доступа.

## API эндпоинты

Модуль `production_client` взаимодействует с сервисом аутентификации (`USER_service`) через следующие API-эндпоинты:
- **Авторизация**: `/api/auth/login`
- **Получение данных пользователя**: `/api/user/data`
- **Обновление пароля**: `/api/user/change_password`

## Зависимости от других частей

1. **API Gateway**: Для маршрутизации запросов к различным сервисам.
2. **USER_service**: Для управления аутентификацией и данными пользователей.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `API Gateway`: Обеспечивает маршрутизацию запросов к различным сервисам.
  
- **Дочерние компоненты**:
  - Компоненты QML: Отображение различных экранов и элементов интерфейса.
  - Мосты между C++ и QML: Обеспечение взаимодействия логики приложения с графическим интерфейсом.

Этот модуль является ключевым компонентом системы ERP, обеспечивающим удобный и интуитивно понятный пользовательский интерфейс для управления проектами и ресурсами инжиниринговых компаний.
