# NAVIGATION_SERVICE/app

## Назначение этой части

Модуль `NAVIGATION_SERVICE/app` является частью бэкенда ERP системы для инжиниринговых компаний. Он предоставляет функциональность навигации, которая позволяет пользователям видеть доступные им панели и сервисы в зависимости от их ролей. Модуль реализован на Python с использованием фреймворка FastAPI и базируется на асинхронной работе с базой данных SQLAlchemy.

## Основные компоненты и их ответственность

1. **api/v1/navigation.py**
   - Содержит маршруты API для взаимодействия с навигационными плитками.
   - Обрабатывает запросы на получение панели навигации (`/dashboard`) и создание новых плиток (`/tiles`).

2. **database.py**
   - Настройка подключения к базе данных SQLite через SQLAlchemy.
   - Создает асинхронные сессии для работы с БД.

3. **main.py**
   - Основной файл приложения FastAPI, который инициализирует приложение и регистрирует маршруты API.
   - Обрабатывает событие запуска приложения для создания таблиц в базе данных.

4. **models/tile.py**
   - Определяет модель данных `Tile` для хранения информации о навигационных плитках в БД.

5. **migrations/add_badge_columns.sql**
   - Скрипт миграции, добавляющий колонки `badge_enabled` и `badge_endpoint` в таблицу `tiles`.

## Ключевые сущности

- **Tile**: Представляет собой навигационную плитку, которая может быть отображена на панели пользователя. Плитка содержит информацию о роли пользователя, метке, эндпоинте, методе HTTP запроса и других параметрах.

## API эндпоинты

1. **GET /api/v1/navigation/dashboard**
   - Возвращает пользователю список доступных ему навигационных плиток с учетом его ролей.
   - Если для плитки включена опция `badge_enabled`, то также запрашивает количество из соответствующего микросервиса и добавляет это к ответу.

2. **POST /api/v1/navigation/tiles**
   - Создает новую навигационную плитку.
   - Доступен только для пользователей с ролью `admin`.

## Зависимости от других частей

- **User Service**: Для получения ролей пользователя по токену авторизации.
- **Другие микросервисы**: Для получения данных для бэйджей (если `badge_enabled` установлено в `True`).

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский модуль**: Модуль `NAVIGATION_SERVICE`, который содержит конфигурационные файлы и скрипты для запуска сервиса.
- **Дочерние компоненты**:
  - `api/v1/navigation.py`: Обрабатывает запросы от клиентов ERP системы.
  - `database.py`: Управляет подключением к базе данных SQLite и предоставляет сессии для работы с ней.
  - `main.py`: Запускает приложение FastAPI и регистрирует маршруты API.
  - `models/tile.py`: Определяет структуру таблицы `tiles` в базе данных.
  - `migrations/add_badge_columns.sql`: Скрипт миграции для добавления новых колонок в таблицу `tiles`.

Этот модуль является важной частью системы навигации ERP, обеспечивающей динамическое отображение доступных сервисов пользователям в зависимости от их ролей.
