# NAVIGATION_SERVICE/app/models

## Назначение этой части

Компонент `NAVIGATION_SERVICE/app/models` отвечает за определение структуры данных, используемых в сервисе навигации ERP системы для инжиниринговых компаний. В частности, он содержит модели данных, которые представляют собой сущности базы данных и используются для взаимодействия с PostgreSQL.

## Основные компоненты и их ответственность

1. **Tile (tile.py)**:
   - Класс `Tile` представляет собой модель данных для таблицы `tiles` в базе данных.
   - Отвечает за хранение информации о различных тайлах навигации, таких как метаданные, конечные точки и методы запросов.

## Ключевые сущности

1. **Tile**:
   - **id**: Уникальный идентификатор тайла.
   - **role**: Роль пользователя, для которой доступен этот тайл.
   - **tile_id**: Уникальный идентификатор тайла внутри системы.
   - **label**: Название или метка тайла.
   - **endpoint**: Конечная точка API, связанная с этим тайлом.
   - **method**: HTTP-метод для запроса к конечной точке (по умолчанию "GET").
   - **icon**: Иконка, ассоциированная с тайлом.
   - **is_active**: Флаг активности тайла.
   - **sort_order**: Порядок сортировки тайлов.
   - **badge_enabled**: Флаг включения бейджа для тайла.
   - **badge_endpoint**: Конечная точка API для получения данных бейджа.
   - **created_at**: Дата и время создания записи.
   - **updated_at**: Дата и время последнего обновления записи.

## API эндпоинты

На текущий момент в данном компоненте нет явно определенных API эндпоинтов. Однако, предполагается, что другие части системы взаимодействуют с моделью `Tile` для выполнения операций CRUD (создание, чтение, обновление и удаление).

## Зависимости от других частей

1. **app.database**: Используется для подключения к базе данных PostgreSQL.
2. **SQLAlchemy**: Библиотека ORM для взаимодействия с базой данных.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - **NAVIGATION_SERVICE/app/database**: Предоставляет подключение к базе данных и необходимые инструменты для работы с ORM.
  
- **Дочерние компоненты**:
  - **NAVIGATION_SERVICE/app/routes**: Использует модели данных для обработки запросов API, связанных с тайлами навигации.

Этот документ описывает структуру и назначение моделей данных в сервисе навигации ERP системы. Для более подробной информации рекомендуется обратиться к полному описанию архитектуры проекта и документации по API.
