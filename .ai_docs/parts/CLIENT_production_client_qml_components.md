# Часть: CLIENT/production_client/qml/components

## Назначение этой части

Часть `CLIENT/production_client/qml/components` проекта ERP для инжиниринговых компаний содержит в себе QML компоненты, используемые в пользовательском интерфейсе клиента. Эти компоненты обеспечивают функциональность и внешний вид различных элементов интерфейса, таких как спиннер загрузки, карточки статуса, индикатор оффлайн режима, предупреждения о сроке действия пароля, список ролей проектов, содержимое вкладок, уведомления, верхняя панель, панель информации пользователя и загрузчик виджетов.

## Основные компоненты и их ответственность

1. **LoadingSpinner.qml**: Отображает спиннер загрузки при выполнении асинхронных операций.
2. **MastergraphStatusCard.qml**: Предполагается, что этот компонент будет отображать статус графика проекта (возможно, используется для интеграции с сервисом Mastergraph).
3. **OfflineIndicator.qml**: Индикатор режима офлайн работы приложения.
4. **PasswordExpiryWarning.qml**: Предупреждает пользователя о скором истечении срока действия пароля.
5. **ProjectRolesList.qml**: Отображает список ролей проектов, к которым имеет доступ пользователь.
6. **TabContent.qml**: Обеспечивает отображение и обновление содержимого вкладок приложения через запросы к API.
7. **ToastNotification.qml**: Показывает уведомления пользователю.
8. **TopBar.qml**: Верхняя панель интерфейса, содержащая логотип, название приложения, информацию о пользователе и кнопки управления (выход, смена пароля, переключение полноэкранного режима).
9. **UserInfoPanel.qml**: Показывает основную информацию о пользователе.
10. **WidgetLoader.qml**: Загружает различные виджеты в зависимости от роли пользователя.

## Ключевые сущности

- **UserData**: Информация о пользователе, используемая в различных компонентах для отображения данных и управления доступом.
- **Projects**: Список проектов, к которым имеет доступ пользователь, используется в `ProjectRolesList.qml`.
- **API Requests**: Запросы к API для получения данных, обновления содержимого вкладок (`TabContent.qml`).

## API эндпоинты

В компоненте `TabContent.qml` используются следующие API эндпоинты:
- **GET endpoint**: Для загрузки и отображения данных в текстовом поле.
- **Authorization Header**: Используется Bearer токен для аутентификации пользователя.

## Зависимости от других частей

1. **API Gateway**: Компоненты, такие как `TabContent.qml`, зависят от API Gateway для выполнения запросов к микросервисам.
2. **USER_service**: Предполагается, что информация о пользователе и его ролях загружается из сервиса управления пользователями.
3. **Проектные данные**: Компоненты `ProjectRolesList.qml` и `TabContent.qml` зависят от данных проектов, которые могут быть предоставлены различными микросервисами.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**: Компоненты в этой директории обычно используются внутри более крупных QML файлов или модулей, таких как `Main.qml` или `MainWindow.qml`.
- **Дочерние компоненты**: Компоненты, такие как `WidgetLoader.qml`, загружают другие QML компоненты (виджеты) в зависимости от роли пользователя.

Эта структура обеспечивает модульность и повторное использование кода, что облегчает поддержку и развитие приложения.
