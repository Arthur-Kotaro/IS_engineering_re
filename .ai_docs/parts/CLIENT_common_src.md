# Часть: CLIENT/common/src

## Назначение этой части

Часть `CLIENT/common/src` проекта ERP для инжиниринговых компаний отвечает за реализацию общих компонентов клиента, таких как взаимодействие с API сервера (авторизация, управление токенами доступа), модели данных пользователей и профилей. Эти компоненты используются различными модулями клиентского приложения для обеспечения единого интерфейса общения с бэкендом и управления данными пользователя.

## Основные компоненты и их ответственность

1. **ApiClient.cpp**
   - **Ответственность**: Обеспечивает взаимодействие с API сервера через HTTP-запросы (GET, POST, PUT, DELETE). Управляет URL-адресом сервера и токенами авторизации.
   
2. **AuthService.cpp**
   - **Ответственность**: Реализует логику аутентификации пользователя, включая вход в систему, обновление токена доступа, получение профиля пользователя и проверку срока действия пароля.

3. **TokenManager.cpp**
   - **Ответственность**: Управляет токенами доступа (access token и refresh token). Предоставляет методы для установки, очистки и обновления токенов, а также сериализации/десериализации их в JSON формат.

4. **UserDataModels.cpp**
   - **Ответственность**: Определяет модели данных пользователей и проектных ролей, которые используются для взаимодействия с API сервера. Включает методы сериализации/десериализации объектов в JSON формат.

5. **UserProfile.cpp**
   - **Ответственность**: Определяет модель данных профиля пользователя и предоставляет методы для её сериализации/десериализации. Также содержит логику определения путей к виджетам на основе ролей пользователя.

## Ключевые сущности

1. **ApiClient**
   - Управляет HTTP-запросами к API сервера.
   
2. **AuthService**
   - Обеспечивает аутентификацию и управление сессией пользователя.
   
3. **TokenManager**
   - Управляет токенами доступа.
   
4. **ProjectRole**
   - Модель данных для проектных ролей пользователей.
   
5. **UserInfo**
   - Модель данных для информации о пользователе.
   
6. **UserProfile**
   - Модель данных для профиля пользователя.

## API эндпоинты

В данной части реализованы следующие API эндпоинты:

1. **POST /login**
   - Авторизация пользователя по email и паролю.
   
2. **GET /users/me**
   - Получение информации о текущем пользователе.
   
3. **GET /users/me/password-expiry**
   - Проверка срока действия пароля пользователя.
   
4. **POST /refresh**
   - Обновление токена доступа по refresh token.

## Зависимости от других частей

- **ApiClient** зависит от `QNetworkAccessManager` для выполнения HTTP-запросов и `QSslConfiguration` для настройки SSL.
- **AuthService** использует `ApiClient` для взаимодействия с API сервера и `TokenManager` для управления токенами доступа.
- **UserDataModels** и **UserProfile** используются различными модулями клиентского приложения для представления данных пользователей.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**: Часть `CLIENT/common/src` используется в других подкаталогах клиента, таких как `engineering_client`, для взаимодействия с API сервера и управления данными пользователя.
- **Дочерние компоненты**: Внутри данной части нет дочерних компонентов, все файлы представляют собой отдельные классы и функции.
