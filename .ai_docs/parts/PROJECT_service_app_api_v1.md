# PROJECT_service/app/api/v1

## Назначение этой части

Часть `PROJECT_service/app/api/v1` является частью бэкенда ERP системы для инжиниринговых компаний, реализованного на Python с использованием фреймворка FastAPI. Она отвечает за предоставление RESTful API для управления проектами компании, включая создание, обновление, удаление и получение информации о проектах, а также управление участниками проектов.

## Основные компоненты и их ответственность

1. **`__init__.py`**: Инициализационный файл для пакета `api/v1`, который может содержать импорты необходимых модулей или функций.
2. **`projects.py`**: Основной файл, содержащий определения маршрутов (эндпоинтов) API для управления проектами.

## Ключевые сущности

- **Проекты**: Основная сущность системы, представляющая собой инженерный проект компании.
- **Участники проектов**: Связь между пользователями и проектами, включающая роль участника (например, менеджер, инженер).
- **Статус проекта**: Перечисление возможных статусов проекта (например, активный, завершенный).

## API эндпоинты

### Получение списка проектов
**GET /api/v1/projects**
- **Описание**: Возвращает список проектов с возможностью фильтрации по статусу и пользователю.
- **Параметры запроса**:
  - `skip`: Смещение для пагинации (по умолчанию 0).
  - `limit`: Ограничение количества возвращаемых проектов (по умолчанию 100, максимум 500).
  - `status`: Фильтр по статусу проекта.
  - `user_id`: ID пользователя для фильтрации проектов, связанных с ним.

### Создание нового проекта
**POST /api/v1/projects**
- **Описание**: Создает новый проект.
- **Параметры запроса**:
  - `data`: Данные о новом проекте (например, название, описание).
  - `created_by`: ID пользователя, создавшего проект.

### Получение информации о проекте
**GET /api/v1/projects/{project_id}**
- **Описание**: Возвращает подробную информацию о конкретном проекте по его ID.
- **Параметры запроса**:
  - `project_id`: ID проекта.

### Обновление информации о проекте
**PUT /api/v1/projects/{project_id}**
- **Описание**: Обновляет информацию о проекте.
- **Параметры запроса**:
  - `project_id`: ID проекта.
  - `data`: Данные для обновления (например, новое название).

### Обновление статуса проекта
**PATCH /api/v1/projects/{project_id}/status**
- **Описание**: Обновляет статус проекта.
- **Параметры запроса**:
  - `project_id`: ID проекта.
  - `data`: Новый статус проекта.

### Удаление проекта
**DELETE /api/v1/projects/{project_id}**
- **Описание**: Удаляет проект по его ID.
- **Параметры запроса**:
  - `project_id`: ID проекта.

### Добавление участника в проект
**POST /api/v1/projects/{project_id}/members**
- **Описание**: Добавляет нового участника в проект.
- **Параметры запроса**:
  - `project_id`: ID проекта.
  - `data`: Данные о новом участнике (ID пользователя и роль).

### Удаление участника из проекта
**DELETE /api/v1/projects/{project_id}/members/{user_id}**
- **Описание**: Удаляет участника из проекта по его ID.
- **Параметры запроса**:
  - `project_id`: ID проекта.
  - `user_id`: ID пользователя, которого нужно удалить.

### Проверка доступа к проекту
**GET /api/v1/projects/{project_id}/check-access**
- **Описание**: Проверяет, имеет ли пользователь доступ к проекту.
- **Параметры запроса**:
  - `project_id`: ID проекта.
  - `user_id`: ID пользователя для проверки.

## Зависимости от других частей

1. **`app/database.py`**: Для получения сессии базы данных и взаимодействия с ORM.
2. **`app/schemas/project.py`**: Схемы данных для валидации запросов и ответов API.
3. **`app/services/project_service.py`**: Сервисный слой, содержащий бизнес-логику управления проектами.
4. **`app/models/project.py`**: Модели базы данных, представляющие структуру таблиц.

## Взаимодействие с родительскими/дочерними компонентами

### Родительские компоненты
- **`PROJECT_service/app/api/__init__.py`**: Инициализационный файл для пакета `api`, который импортирует маршруты из подпакетов, таких как `v1`.

### Дочерние компоненты
- Отсутствуют непосредственные дочерние компоненты в данном каталоге. Все необходимые модули и сервисы находятся на одном уровне или выше.

Эта часть проекта является ключевым элементом API для управления проектами, обеспечивая взаимодействие между клиентской частью ERP системы и базой данных через структурированный набор эндпоинтов.
