# NAVIGATION_SERVICE/app/migrations

## Назначение этой части

Компонент `NAVIGATION_SERVICE/app/migrations` предназначен для хранения SQL-скриптов, которые изменяют структуру базы данных сервиса навигации. Эти скрипты используются для добавления новых столбцов, таблиц или других элементов базы данных в процессе разработки и поддержания системы.

## Основные компоненты и их ответственность

1. **add_badge_columns.sql**: SQL-скрипт, который добавляет новые колонки `badge_enabled` и `badge_endpoint` в таблицу `tiles`. Эти колонки используются для управления отображением значков (пузырьков) на карте.

## Ключевые сущности

1. **Таблица tiles**: Основная таблица базы данных, которая хранит информацию о тайлах карты.
2. **Колонки badge_enabled и badge_endpoint**:
   - `badge_enabled`: Логическое значение, указывающее, включены ли значки для данного тайла.
   - `badge_endpoint`: Строка, содержащая URL-адрес конечной точки для получения данных значков.

## API эндпоинты

В данном компоненте нет определенных API эндпоинтов. Он предназначен исключительно для миграций базы данных.

## Зависимости от других частей (если известны)

1. **NAVIGATION_SERVICE**: Этот компонент является частью сервиса навигации, который использует базу данных с таблицей `tiles`.
2. **PostgreSQL**: База данных, на которой выполняются миграции.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент**: `NAVIGATION_SERVICE` — сервис навигации, который использует базу данных и требует выполнения миграций для обновления структуры таблиц.
- **Дочерние компоненты**: Отсутствуют, так как этот компонент содержит только скрипты миграции.

## Пример содержимого файла `add_badge_columns.sql`

```sql
-- add_badge_columns.sql
-- Добавляем колонки для пузырьков

ALTER TABLE tiles ADD COLUMN badge_enabled BOOLEAN DEFAULT FALSE;
ALTER TABLE tiles ADD COLUMN badge_endpoint VARCHAR(200) DEFAULT NULL;
```

Этот скрипт добавляет две новые колонки в таблицу `tiles`, что позволяет управлять отображением значков на карте.
