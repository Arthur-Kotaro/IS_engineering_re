# Часть: CLIENT/common/include

## Назначение этой части

Часть `CLIENT/common/include` проекта ERP для инжиниринговых компаний содержит заголовочные файлы, определяющие основные компоненты и структуры данных для взаимодействия с пользовательскими сервисами. Эти файлы обеспечивают абстракцию над сетевыми запросами, управлением аутентификацией и хранением данных пользователя.

## Основные компоненты и их ответственность

1. **ApiClient.h**
   - Класс `ApiClient` предоставляет интерфейс для выполнения HTTP-запросов к серверу.
   - Отвечает за установку URL-адреса сервера, управление токенами аутентификации и выполнение GET, POST, PUT и DELETE запросов.

2. **AuthService.h**
   - Класс `AuthService` отвечает за аутентификацию пользователя, обновление токенов доступа, сброс пароля и получение информации о пользователе.
   - Использует экземпляр `ApiClient` для выполнения сетевых запросов.

3. **TokenManager.h**
   - Класс `TokenManager` управляет хранением и проверкой действительности токенов доступа и обновления.
   - Предоставляет методы для установки, очистки и обновления токенов.

4. **UserDataModels.h**
   - Содержит структуры данных `ProjectRole` и `UserInfo`, которые представляют роли пользователя в проектах и информацию о пользователе соответственно.
   - Методы `toJson()` и `fromJson()` позволяют сериализовать и десериализовать данные в формате JSON.

5. **UserProfile.h**
   - Структура данных `UserProfile` содержит подробную информацию о профиле пользователя, включая статус, роли и проекты.
   - Методы `toJson()` и `fromJson()` позволяют сериализовать и десериализовать данные в формате JSON.

6. **UsersServiceClient_global.h**
   - Определяет макросы для экспорта/импорта символов библиотеки, что необходимо для создания и использования динамических библиотек на платформах Qt.

## Ключевые сущности

- **ApiClient**: Обеспечивает сетевое взаимодействие с сервером.
- **AuthService**: Управляет аутентификацией пользователя.
- **TokenManager**: Хранит и управляет токенами доступа и обновления.
- **ProjectRole**: Представляет роль пользователя в проекте.
- **UserInfo**: Содержит информацию о пользователе.
- **UserProfile**: Детальная информация о профиле пользователя.

## API эндпоинты

В данной части нет прямого определения API эндпоинтов, но класс `ApiClient` предоставляет методы для выполнения запросов к следующим типам эндпоинтов:
- **GET**: Получение данных.
- **POST**: Отправка данных (например, при регистрации или изменении пароля).
- **PUT**: Обновление данных.
- **DELETE**: Удаление данных.

## Зависимости от других частей

- **ApiClient** зависит от `QNetworkAccessManager` для выполнения сетевых запросов и `QJsonDocument` для работы с JSON данными.
- **AuthService** использует экземпляр `ApiClient` для выполнения сетевых запросов к серверу аутентификации.
- **TokenManager** не имеет внешних зависимостей, кроме стандартных библиотек Qt.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**: Часть `CLIENT/common/include` используется в других модулях клиента для выполнения сетевых запросов и управления аутентификацией.
- **Дочерние компоненты**: Отсутствуют, так как это заголовочные файлы, которые предоставляют интерфейсы для использования другими частями проекта.

Эта часть проекта обеспечивает структурированное взаимодействие с пользовательскими сервисами и управление аутентификацией, что является критическим компонентом функциональности ERP системы.
