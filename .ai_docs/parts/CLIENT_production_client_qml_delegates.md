# CLIENT/production_client/qml/delegates

## Назначение этой части

Часть проекта `CLIENT/production_client/qml/delegates` отвечает за визуальное представление элементов данных (например, мастерграфы, проекты и роли) в пользовательском интерфейсе ERP системы для инжиниринговых компаний. Делегаты используются для настройки внешнего вида и поведения элементов списка или других компонентов Qt Quick.

## Основные компоненты и их ответственность

1. **MastergraphDelegate.qml**
   - Отвечает за отображение данных мастерграфа.
   
2. **ProjectDelegate.qml**
   - Отвечает за отображение данных проекта.
   
3. **RoleDelegate.qml**
   - Отвечает за отображение данных роли.

## Ключевые сущности

- `modelData`: Объект, содержащий данные для отображения в делегате.
  - `name`: Имя элемента (мастерграфа, проекта или роли).
  - `role`: Роль пользователя (если применимо).

## API эндпоинты

Делегаты сами не взаимодействуют с API. Они получают данные через модели данных Qt Quick и отображают их.

## Зависимости от других частей

- **CLIENT/production_client/qml**: Делегаты используются в списках или других компонентах, расположенных в этом каталоге.
- **COMMON/common/include/userserviceclient**: Предоставляет клиентские классы для взаимодействия с сервисами пользователей, которые могут быть источником данных для делегатов.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**: Делегаты используются в списках (например, `ListView` или `Repeater`) и других контейнерах Qt Quick для отображения элементов данных.
- **Дочерние компоненты**: Внутри делегатов используется компонент `Text`, который отвечает за отображение текстовой информации.

### Пример использования

```qml
ListView {
    model: mastergraphModel // Предполагается, что есть модель данных для мастерграфов
    delegate: MastergraphDelegate { }
}
```

Таким образом, делегаты обеспечивают гибкое и удобное отображение различных типов данных в пользовательском интерфейсе ERP системы.
