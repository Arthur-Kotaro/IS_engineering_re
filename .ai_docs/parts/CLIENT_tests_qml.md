# CLIENT/tests/qml

## Назначение этой части

Каталог `CLIENT/tests/qml` предназначен для хранения тестовых сценариев, написанных на QML, которые используются для автоматического тестирования пользовательского интерфейса клиента ERP системы для инжиниринговых компаний. Эти тесты помогают обеспечить корректную работу графических элементов и взаимодействия пользователя с приложением.

## Основные компоненты и их ответственность

1. **TestAuthWindow.qml**: Этот файл содержит тестовый сценарий для окна аутентификации (авторизации) в клиентском приложении ERP. Он проверяет правильность отображения элементов интерфейса, корректность обработки пользовательского ввода и взаимодействия с сервисом авторизации.

## Ключевые сущности

- **Окно аутентификации**: Тестируемый графический элемент интерфейса, который позволяет пользователям вводить свои учетные данные для входа в систему.
- **Сервис авторизации**: Внешний сервис, который проверяет правильность предоставленных пользователем данных и выдает токен доступа.

## API эндпоинты

Тесты в этом каталоге могут взаимодействовать с следующими API эндпоинтами:

- **POST /api/auth/login**: Эндпоинт для аутентификации пользователя. Принимает логин и пароль, проверяет их на сервере и возвращает токен доступа.

## Зависимости от других частей

1. **CLIENT/common/include/userserviceclient/ApiClient.h**: Класс `ApiClient` используется для взаимодействия с API сервисов.
2. **CLIENT/common/include/userserviceclient/AuthService.h**: Класс `AuthService` предоставляет методы для аутентификации пользователя и управления токенами доступа.
3. **API_Gateway/nginx/conf.d/gateway.conf**: Конфигурация Nginx, которая маршрутизирует запросы к соответствующим сервисам.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский каталог (CLIENT/tests)**: Каталог `qml` является подкаталогом тестов, который специализируется на QML-тестах.
- **Дочерние элементы**: В данном случае дочерних элементов нет, так как в каталоге содержится только один файл с тестовым сценарием.

Этот раздел документации описывает структуру и назначение тестовых сценариев на QML для клиента ERP системы. Он помогает разработчикам понимать, какие тесты существуют и как они взаимодействуют с другими частями проекта.
