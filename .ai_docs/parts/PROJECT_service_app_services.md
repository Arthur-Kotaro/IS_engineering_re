# Компонент PROJECT_service/app/services

## Назначение этой части

Компонент `PROJECT_service/app/services` отвечает за бизнес-логику приложения, связанную с управлением проектами. Он предоставляет методы для создания, обновления, удаления и получения информации о проектах, а также для управления участниками проекта.

## Основные компоненты и их ответственность

1. **`__init__.py`**: Файл инициализации модуля, который позволяет Python рассматривать директорию как пакет.
2. **`project_service.py`**: Основной файл сервиса проектов, содержащий класс `ProjectService`, который реализует бизнес-логику управления проектами.

## Ключевые сущности

1. **`ProjectService`**: Класс, предоставляющий методы для работы с проектами.
2. **`ProjectRepository`**: Репозиторий, отвечающий за взаимодействие с базой данных для выполнения операций над проектами.
3. **Схемы данных**:
   - `ProjectCreate`: Схема для создания нового проекта.
   - `ProjectUpdate`: Схема для обновления существующего проекта.
   - `ProjectResponse`: Схема ответа для получения списка проектов.
   - `ProjectDetailResponse`: Схема ответа для получения детальной информации о проекте.
   - `CheckAccessResponse`: Схема ответа для проверки доступа пользователя к проекту.

## API эндпоинты

В данном компоненте не определены конкретные API эндпоинты. Однако, предполагается, что он будет использоваться в контроллерах или маршрутизаторах FastAPI для обработки запросов, связанных с проектами.

## Зависимости от других частей

1. **`app.repositories.project_repo`**: Модуль репозитория, который предоставляет методы для взаимодействия с базой данных.
2. **`app.schemas.project`**: Модуль схем, содержащий модели данных для создания, обновления и ответов проектов.
3. **`app.models.project`**: Модель данных проекта, используемая в SQLAlchemy для взаимодействия с базой данных.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `PROJECT_service/app`: Основной пакет приложения, который содержит все сервисные и репозиторийные модули.
  
- **Дочерние компоненты**:
  - Нет прямых дочерних компонентов в данном каталоге. Однако, `project_service.py` взаимодействует с репозиторием проектов и использует модели данных.

Этот компонент является ключевым для управления проектами в ERP-системе инжиниринговых компаний, обеспечивая необходимые методы для работы с проектами и их участниками.
