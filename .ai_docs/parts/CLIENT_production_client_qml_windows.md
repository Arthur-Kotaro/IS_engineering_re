# Описание части CLIENT/production_client/qml/windows

## 1. Назначение этой части

Часть `CLIENT/production_client/qml/windows` проекта ERP для инжиниринговых компаний отвечает за графические интерфейсы пользовательского ввода (GUI) на стороне клиента. В частности, она содержит основные окна приложения: экран входа (`AuthWindow.qml`), главное окно после авторизации (`MainWindow.qml`) и экран приветствия во время загрузки приложения (`SplashScreen.qml`). Эти компоненты обеспечивают взаимодействие пользователя с системой, предоставляя интерфейсы для аутентификации, основного функционала и индикации процесса запуска.

## 2. Основные компоненты и их ответственность

### AuthWindow.qml
- **Назначение:** Предоставляет форму входа в систему.
- **Компоненты:**
  - `TextField` для ввода email и пароля.
  - `Button` для выполнения аутентификации.
  - `BusyIndicator` для отображения состояния процесса входа.

### MainWindow.qml
- **Назначение:** Основное окно приложения после успешной авторизации, содержащее верхнюю панель с информацией о пользователе и рабочее пространство с вкладками.
- **Компоненты:**
  - Верхняя панель (`topBar`) с информацией о пользователе, состоянием пароля и кнопками для изменения темы, смены пароля и выхода из системы.
  - `TabBar` и `StackLayout` для управления вкладками.

### SplashScreen.qml
- **Назначение:** Отображает экран приветствия во время запуска приложения.
- **Компоненты:**
  - Простой текст "Загрузка..." на фоне синего цвета.

## 3. Ключевые сущности

### AuthWindow.qml
- `emailField`: Поле ввода для адреса электронной почты.
- `passwordField`: Поле ввода пароля, которое маскирует символы.
- `loginBusy`: Индикатор загрузки при выполнении входа.

### MainWindow.qml
- `topBar`: Верхняя панель с информацией о пользователе и кнопками управления.
- `tabBar`: Панель вкладок для навигации по различным разделам приложения.
- `stackLayout`: Стэклайоут, который отображает содержимое текущей выбранной вкладки.

### SplashScreen.qml
- Простой текст "Загрузка..." с белым цветом на синем фоне.

## 4. API эндпоинты

В данном разделе нет прямых вызовов API, так как это графические интерфейсы пользовательского ввода. Однако, `AuthWindow.qml` предполагает взаимодействие с сервером для выполнения аутентификации пользователя. Предположительные эндпоинты могут быть следующими:
- **POST /api/auth/login**: Для отправки данных аутентификации (email и пароль) на сервер.

## 5. Зависимости от других частей

### CLIENT/production_client/qml/windows/AuthWindow.qml
- Зависит от модулей `QtQuick`, `QtQuick.Controls` и `QtQuick.Layouts`.
- Использует стили из каталога `../styles`.

### CLIENT/production_client/qml/windows/MainWindow.qml
- Зависит от модулей `QtQuick`, `QtQuick.Controls` и `QtQuick.Layouts`.
- Использует стили из каталога `../styles`.
- Импортирует диалоги из каталога `../dialogs`.

### CLIENT/production_client/qml/windows/SplashScreen.qml
- Зависит от модуля `QtQuick`.

## 6. Взаимодействие с родительскими/дочерними компонентами

### Родительские компоненты:
- **Клиентское приложение:** Эти окна являются частью основного интерфейса пользователя и взаимодействуют с другими модулями клиента для выполнения различных функций.

### Дочерние компоненты:
- **AuthWindow.qml:** Содержит элементы управления (`TextField`, `Button`), которые обеспечивают ввод данных пользователем.
- **MainWindow.qml:** Включает в себя дочерние компоненты, такие как `topBar`, `tabBar` и `stackLayout`.
- **SplashScreen.qml:** Не имеет дочерних компонентов.

Эта часть проекта обеспечивает удобный и интуитивно понятный пользовательский интерфейс для взаимодействия с системой ERP.
