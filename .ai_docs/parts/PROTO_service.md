# PROTO Service

## Назначение этой части

**PROTO Service** является микросервисом в ERP-системе для инжиниринговых компаний. Его основная задача — предоставление прототипных данных и функциональности, которые могут быть расширены или модифицированы в дальнейшем. Этот сервис может использоваться для тестирования новых функций, разработки API или демонстрации возможностей системы.

## Основные компоненты и их ответственность

1. **run.sh**:
   - **Функциональность**: Скрипт запускает PROTO Service с использованием Uvicorn.
   - **Ответственность**: Управление окружением (активация виртуального окружения, если оно существует) и запуск сервера FastAPI на порту 8004.

## Ключевые сущности

На текущий момент ключевые сущности PROTO Service не полностью определены. Однако, исходя из названия сервиса, можно предположить, что он может включать следующие сущности:
- Прототипные данные для тестирования.
- Модели данных для демонстрации возможностей системы.

## API эндпоинты

На текущий момент конкретные API эндпоинты не определены. Однако, исходя из структуры проекта и использования FastAPI, можно предположить, что они могут включать следующие:
- **GET /ping**: Проверка доступности сервиса.
- **POST /data**: Получение или отправка прототипных данных.

## Зависимости от других частей

PROTO Service зависит от следующих компонентов проекта:
- **API Gateway**: Для маршрутизации запросов к PROTO Service.
- **База данных (PostgreSQL)**: Если требуется хранение прототипных данных.

## Взаимодействие с родительскими/дочерними компонентами

PROTO Service взаимодействует с другими микросервисами и клиентской частью системы следующим образом:
- **API Gateway**: Получает запросы от API Gateway, обрабатывает их и возвращает результат.
- **Клиентская часть (Qt/QML)**: Может использовать API PROTO Service для получения прототипных данных или тестирования новых функций.

## Пример запуска

Для запуска PROTO Service выполните следующую команду из корневого каталога проекта:

```bash
cd PROTO_service
./run.sh
```

Это активирует виртуальное окружение (если оно существует) и запустит сервис на порту 8004 с использованием Uvicorn.
