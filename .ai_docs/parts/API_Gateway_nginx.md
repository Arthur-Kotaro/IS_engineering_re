# API Gateway (Nginx)

## Назначение этой части

Модуль `API_Gateway/nginx` отвечает за маршрутизацию HTTP-запросов к различным микросервисам системы ERP для инжиниринговых компаний. Nginx используется как обратный прокси-сервер, который принимает входящие запросы и перенаправляет их соответствующим сервисам в зависимости от URL-пути.

## Основные компоненты и их ответственность

1. **Nginx**: Основной сервер, который обрабатывает HTTP/HTTPS-запросы.
2. **Конфигурационные файлы**:
   - `nginx.conf`: Основной конфигурационный файл Nginx, где определяются глобальные настройки и включаются дополнительные конфиги из директории `conf.d`.
   - `gateway.conf`: Конфигурационный файл для маршрутизации запросов к различным микросервисам.

## Ключевые сущности

- **Запросы**: HTTP/HTTPS-запросы, поступающие на API Gateway.
- **Маршруты**: Правила маршрутизации запросов в зависимости от URL-пути.
- **Прокси**: Перенаправление запросов к соответствующим микросервисам.

## API эндпоинты

1. **Проверка здоровья Gateway**:
   - `GET /health`: Возвращает статус "Gateway is healthy".
   
2. **Маршрутизация запросов к User Service**:
   - `POST /api/v1/auth/`: Аутентификация пользователя.
   - `GET /api/v1/users/`: Получение информации о пользователе.
   - `PUT /api/v1/admin/`: Административные действия над пользователями.
   - `GET /api/v1/navigation/`: Навигация по системе.

3. **Маршрутизация запросов к Project Service**:
   - `POST /api/v1/projects/`: Создание нового проекта.

4. **Проверка здоровья всех сервисов (агрегированный)**:
   - `GET /health/all`: Возвращает статус "All services are healthy".

5. **Корневой путь**:
   - `GET /`: Возвращает сообщение "API Gateway is running".

## Зависимости от других частей

- **User Service**: Обрабатывает запросы, связанные с аутентификацией и управлением пользователями.
- **Project Service**: Обрабатывает запросы, связанные с созданием и управлением проектами.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент**: `API_Gateway` — модуль, который включает в себя Nginx для маршрутизации запросов.
- **Дочерние компоненты**:
  - `User Service`: Получает запросы по путям `/api/v1/auth/`, `/api/v1/users/`, `/api/v1/admin/` и `/api/v1/navigation/`.
  - `Project Service`: Получает запросы по пути `/api/v1/projects/`.

Nginx в данном модуле выполняет роль центрального узла для маршрутизации запросов между различными микросервисами системы ERP, обеспечивая эффективное управление трафиком и поддержку масштабируемости.
