# NAVIGATION_SERVICE/app/api/v1

## Назначение этой части

Модуль `NAVIGATION_SERVICE/app/api/v1` является частью бэкенда ERP системы для инжиниринговых компаний. Он предоставляет API для управления навигационными плитками и получения данных для дашборда пользователя.

## Основные компоненты и их ответственность

### `__init__.py`
- **Ответственность**: Импортирует модуль `navigation` в текущее пространство имен, делая его доступным для использования в других частях приложения.

### `navigation.py`
- **Ответственность**: Определяет маршруты API для взаимодействия с навигационными плитками и дашбордом пользователя. Включает функции для получения ролей пользователя, подсчета значений бейджей и управления плитками.

## Ключевые сущности

### `Tile`
- **Описание**: Модель данных, представляющая навигационную плитку в базе данных. Содержит информацию о роли пользователя, идентификаторе плитки, метке, эндпоинте, методе HTTP запроса, значке, порядке сортировки, флаге бейджа и эндпоинте бейджа.

## API эндпоинты

### `GET /dashboard`
- **Описание**: Возвращает данные для дашборда пользователя.
- **Параметры**:
  - Авторизация: Bearer token
- **Ответ**:
  ```json
  {
    "tiles": [
      {
        "id": "tile_id",
        "label": "Tile Label",
        "endpoint": "/api/endpoint",
        "method": "GET",
        "icon": "icon.png",
        "badge_count": 10
      }
    ],
    "user_roles": ["admin", "user"]
  }
  ```

### `POST /tiles`
- **Описание**: Создает новую навигационную плитку.
- **Параметры**:
  - Авторизация: Bearer token (только для администраторов)
  - Тело запроса:
    ```json
    {
      "role": "admin",
      "tile_id": "new_tile",
      "label": "New Tile",
      "endpoint": "/api/new_endpoint",
      "method": "POST",
      "icon": "new_icon.png",
      "sort_order": 1,
      "badge_enabled": true,
      "badge_endpoint": "/api/badge"
    }
    ```
- **Ответ**:
  ```json
  {
    "message": "Tile created",
    "tile_id": "new_tile"
  }
  ```

## Зависимости от других частей

### `USER_service`
- **Описание**: Модуль `navigation.py` зависит от сервиса пользователей для получения ролей пользователя по токену авторизации.

### `DATABASE`
- **Описание**: Используется для хранения и извлечения данных о навигационных плитках.

## Взаимодействие с родительскими/дочерними компонентами

### Родительский компонент
- **Описание**: Модуль `app/api/v1` является частью большего приложения `NAVIGATION_SERVICE`, который управляет всеми API версии 1.

### Дочерние компоненты
- **Отсутствуют**, так как в данном модуле нет подмодулей или дополнительных компонентов.
