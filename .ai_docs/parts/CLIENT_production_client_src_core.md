# Часть: CLIENT/production_client/src/core

## Назначение этой части

Часть `CLIENT/production_client/src/core` проекта ERP для инжиниринговых компаний отвечает за основные компоненты и функциональность клиентского приложения. Она включает в себя классы, которые обеспечивают конфигурацию приложения, управление кэшем данных и инициализацию ядра приложения.

## Основные компоненты и их ответственность

1. **AppCore**
   - **Назначение**: Ядро приложения, отвечающее за его инициализацию.
   - **Методы**:
     - `init()`: Метод для инициализации приложения.

2. **CacheManager**
   - **Назначение**: Управление кэшем данных приложения.
   - **Методы**:
     - `loadLastModifiedDates(QMap<int, QDateTime>& dates)`: Загрузка дат последнего изменения данных из кэша.
     - `saveLastModifiedDates(const QMap<int, QDateTime>& dates)`: Сохранение дат последнего изменения данных в кэш.

3. **ConfigManager**
   - **Назначение**: Управление конфигурацией приложения, такими параметрами как адрес и порт сервера.
   - **Методы**:
     - `getServerHost() const`: Получение хоста сервера.
     - `getServerPort() const`: Получение порта сервера.

## Ключевые сущности

- **AppCore**: Ядро приложения, которое инициализирует все необходимые компоненты.
- **CacheManager**: Менеджер кэша данных для оптимизации производительности приложения.
- **ConfigManager**: Менеджер конфигурации для управления параметрами подключения к серверу.

## API эндпоинты

В данной части проекта нет прямых API эндпоинтов, так как она отвечает за внутреннюю логику клиента. Однако, классы `CacheManager` и `ConfigManager` могут использоваться для взаимодействия с сервером через API.

## Зависимости от других частей

- **API Gateway**: Используется для маршрутизации запросов между клиентским приложением и микросервисами.
- **USER_service**: Может быть вызван через API для аутентификации и управления пользователями.
- **Другие микросервисы**: Данные микросервисы могут взаимодействовать с клиентом через API Gateway.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `CLIENT/production_client/src`: Ядро клиента, который использует классы из `core` для инициализации и управления конфигурацией.
  
- **Дочерние компоненты**:
  - Классы из `core` используются другими частями клиентского приложения для выполнения задач по управлению кэшем и конфигурацией.
