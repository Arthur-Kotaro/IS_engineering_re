# CLIENT/production_client/config

## Назначение этой части

Каталог `CLIENT/production_client/config` содержит конфигурационные файлы для клиента ERP системы, предназначенного для использования в производственной среде. Эти файлы определяют параметры подключения к серверу, настройки логирования и другие важные параметры, необходимые для корректной работы клиентского приложения.

## Основные компоненты и их ответственность

1. **default_config.json**
   - **Ответственность**: Хранит основные конфигурационные параметры клиента, такие как URL сервера API, таймауты подключения, настройки безопасности и другие необходимые данные для работы приложения.

2. **logging_config.ini**
   - **Ответственность**: Определяет параметры логирования, включая уровень логирования (например, DEBUG, INFO, WARNING, ERROR), формат сообщений, пути к файлам логов и другие настройки для сбора информации о работе приложения.

## Ключевые сущности

1. **Конфигурационные параметры**
   - URL сервера API
   - Таймауты подключения
   - Настройки безопасности (например, токены доступа)

2. **Настройки логирования**
   - Уровень логирования
   - Формат сообщений
   - Пути к файлам логов

## API эндпоинты

В данном каталоге нет файлов с описанием API эндпоинтов, так как он предназначен для хранения конфигурационных данных. Описание API эндпоинтов находится в других частях проекта, например, в `.ai_docs/api/endpoints.md`.

## Зависимости от других частей

1. **API Gateway**
   - Клиент использует параметры подключения к серверу API, которые определены в `default_config.json`.

2. **USER_service**
   - Настройки аутентификации и авторизации могут быть связаны с конфигурационными данными из этого сервиса.

3. **Другие микросервисы**
   - Конфигурационные параметры могут влиять на взаимодействие клиента с различными микросервисами, такими как `PROJECT_service`, `PROTO_service` и др.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент**: `CLIENT/production_client`
  - Конфигурационные файлы из этого каталога используются для настройки основных параметров работы клиента ERP.

- **Дочерние компоненты**:
  - Непосредственно в данном каталоге нет дочерних компонентов, но конфигурационные данные могут влиять на работу различных модулей и подсистем внутри `CLIENT/production_client`.
