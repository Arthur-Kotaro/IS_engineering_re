# NAVIGATION_SERVICE/app/api

## Назначение этой части

Компонент `NAVIGATION_SERVICE/app/api` отвечает за предоставление API-интерфейса для взаимодействия с навигационными сервисами ERP системы. Этот компонент обеспечивает доступ к информации о плитках (tiles), которые представляют различные функциональные возможности системы, а также управление этими плитками.

## Основные компоненты и их ответственность

1. **`__init__.py`**: Инициализация модуля `v1`, который содержит основную логику API.
2. **`navigation.py`**: Содержит определения маршрутов (эндпоинтов) для взаимодействия с навигационными данными.

## Ключевые сущности

- **Tile**: Представляет собой элемент интерфейса, который может быть отображен на панели навигации. У каждой плитки есть метка (label), конечная точка (endpoint), метод запроса (method), иконка (icon) и другие атрибуты.
- **Role**: Роль пользователя, определяющая доступные ему плитки.

## API эндпоинты

1. **GET /dashboard**
   - **Описание**: Возвращает информацию о плитках для текущего пользователя на основе его ролей. Если у плитки включена поддержка бэйджей (`badge_enabled`), также возвращается количество, полученное из соответствующего микросервиса.
   - **Параметры запроса**:
     - `Authorization`: Токен авторизации пользователя.
   - **Ответ**: JSON-объект с массивом плиток и ролями пользователя.

2. **POST /tiles**
   - **Описание**: Создает новую плитку в системе. Доступно только для пользователей с ролью администратора.
   - **Параметры запроса**:
     - `Authorization`: Токен авторизации пользователя.
     - `tile_data`: JSON-объект с данными о создаваемой плитке (например, `role`, `tile_id`, `label` и т.д.).
   - **Ответ**: Сообщение об успешном создании плитки и её уникальный идентификатор.

## Зависимости от других частей

- **User Service**: Для получения ролей пользователя по переданному токену авторизации.
- **База данных (PostgreSQL)**: Для хранения информации о плитках и их настройках.
- **Другие микросервисы**: Для получения бэйдж-контента, если он включен для плитки.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент**: `NAVIGATION_SERVICE/app` — модуль, который содержит общую логику и настройки навигационного сервиса.
- **Дочерние компоненты**:
  - **Маршруты (эндпоинты)**: Определены в `navigation.py`, предоставляют интерфейс для взаимодействия с внешними системами и клиентскими приложениями.
  - **Вспомогательные функции**: Такие как `get_user_roles` и `get_badge_count`, обеспечивают необходимую логику для работы маршрутов.

Этот компонент является ключевым элементом системы навигации, обеспечивая динамическое формирование интерфейса в зависимости от ролей пользователей и предоставление администратору возможности управлять доступными функциями.
