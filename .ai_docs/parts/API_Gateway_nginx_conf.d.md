# Компонент API Gateway (Nginx Configuration)

## Назначение этой части

Компонент `API Gateway` включает в себя конфигурацию Nginx, которая служит как единую точку входа для всех клиентских запросов к различным микросервисам системы ERP для инжиниринговых компаний. Nginx используется для маршрутизации запросов, балансировки нагрузки и управления трафиком между клиентами и внутренними сервисами.

## Основные компоненты и их ответственность

1. **Nginx Server Block**:
   - Отвечает за настройку веб-сервера Nginx, который прослушивает порт 80.
   - Обрабатывает входящие запросы и перенаправляет их к соответствующим микросервисам.

2. **Логирование**:
   - `access_log` и `error_log`: сохраняют информацию о доступах к серверу и возникающих ошибках соответственно.

3. **Health Check Endpoints**:
   - `/health`: проверяет здоровье самого API Gateway.
   - `/health/all`: агрегированный эндпоинт для проверки здоровья всех сервисов системы.

4. **Proxy Pass Directives**:
   - Перенаправляют запросы к различным микросервисам в зависимости от пути запроса.

## Ключевые сущности

- **Nginx**: Веб-сервер и обратный прокси.
- **Server Block**: Конфигурационный блок Nginx, который определяет параметры сервера.
- **Proxy Pass**: Директива Nginx для перенаправления запросов к другим серверам или сервисам.

## API эндпоинты

1. **Health Check**:
   - `/health`: Возвращает статус здоровья API Gateway.
     ```
     GET /health
     Response: 200 OK, "Gateway is healthy\n"
     ```

   - `/health/all`: Возвращает агрегированный статус здоровья всех сервисов системы.
     ```
     GET /health/all
     Response: 200 OK, "All services are healthy\n"
     ```

2. **User Service**:
   - `/api/v1/auth/`: Перенаправляет запросы к микросервису аутентификации пользователей.
   - `/api/v1/users/`: Перенаправляет запросы к микросервису управления пользователями.
   - `/api/v1/admin/`: Перенаправляет запросы к микросервису администрирования.

3. **Project Service**:
   - `/api/v1/projects/`: Перенаправляет запросы к микросервису управления проектами.

## Зависимости от других частей

- **User_service**: Микросервис, который обрабатывает запросы по аутентификации и управлению пользователями.
- **PROJECT_service**: Микросервис, который обрабатывает запросы по управлению проектами.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский Компонент**: `API_Gateway` - основной сервис, который включает в себя конфигурацию Nginx.
- **Дочерние Компоненты**:
  - Микросервисы (`User_service`, `PROJECT_service` и другие), к которым перенаправляются запросы через API Gateway.
