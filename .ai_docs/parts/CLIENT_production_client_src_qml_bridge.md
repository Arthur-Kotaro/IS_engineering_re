# CLIENT/production_client/src/qml_bridge

## Назначение этой части

Каталог `CLIENT/production_client/src/qml_bridge` содержит реализацию мостов (bridges) между QML-интерфейсом и бизнес-логикой приложения ERP для инжиниринговых компаний. Эти мосты обеспечивают взаимодействие пользовательского интерфейса с сервисами аутентификации, загрузкой данных профиля пользователя и уведомлениями.

## Основные компоненты и их ответственность

1. **AuthBridge.cpp / AuthBridge.h**
   - **Назначение**: Обеспечивает взаимодействие с сервисами аутентификации.
   - **Ответственность**:
     - Попытка входа пользователя (`attemptLogin`).
     - Выход пользователя из системы (`logout`).
     - Обработка результата попытки входа (`onLoginCompleted`).

2. **MainWindowBridge.cpp / MainWindowBridge.h**
   - **Назначение**: Предоставляет доступ к данным профиля пользователя и управлению паролем.
   - **Ответственность**:
     - Получение информации о пользователе, таких как имя, email, должность (`userName`, `userEmail`, `userPosition`).
     - Управление паролями: изменение пароля (`changePassword`) и проверка срока действия пароля (`checkPasswordExpiry`).
     - Загрузка данных для отображения на главном окне (`loadTiles`).

3. **NotificationBridge.cpp / NotificationBridge.h**
   - **Назначение**: Предоставляет функциональность для работы с уведомлениями.
   - **Ответственность**:
     - В настоящее время реализация пустая, но предназначена для обработки уведомлений от сервера.

## Ключевые сущности

- **AuthBridge**: Объект, предоставляющий методы для аутентификации пользователя.
- **MainWindowBridge**: Объект, предоставляющий доступ к данным профиля пользователя и управлению паролями.
- **NotificationBridge**: Объект, предназначенный для работы с уведомлениями.

## API эндпоинты

В данном каталоге нет явного определения API эндпоинтов. Однако, `MainWindowBridge` использует следующий эндпоинт для загрузки данных тайлов:

- **GET /api/v1/navigation/dashboard**: Запрос к Navigation Service для получения данных тайлов.

## Зависимости от других частей

- **userserviceclient/AuthService.h**: Используется для взаимодействия с сервисами аутентификации.
- **userserviceclient/UserProfile.h**: Используется для хранения и предоставления данных профиля пользователя.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `CLIENT/production_client/src`: Каталог, содержащий основной код клиента.
  
- **Дочерние компоненты**:
  - Ниже нет подкаталогов, но файлы в этом каталоге взаимодействуют с QML-интерфейсом через свойства и методы, объявленные в заголовочных файлах.

Этот раздел обеспечивает интеграцию между бизнес-логикой приложения и пользовательским интерфейсом, используя механизмы Qt для взаимодействия C++ и QML.
