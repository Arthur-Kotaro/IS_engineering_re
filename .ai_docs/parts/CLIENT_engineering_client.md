# CLIENT/engineering_client

## Назначение этой части

Модуль `engineering_client` является консольным приложением для взаимодействия с микросервисами пользователей в ERP-системе для инжиниринговых компаний. Он предоставляет интерфейс для выполнения операций, связанных с аутентификацией и управлением учетными записями пользователей, таких как вход в систему, проверка срока действия пароля, изменение пароля, обновление токена доступа и выход из системы.

## Основные компоненты и их ответственность

1. **main.cpp**:
   - Точка входа в приложение.
   - Инициализирует объект `EngineeringConsoleUI` с параметрами хоста и порта сервера.
   - Запускает основной цикл приложения.

2. **EngineeringConsoleUI.h** и **EngineeringConsoleUI.cpp**:
   - Класс `EngineeringConsoleUI`, который управляет пользовательским интерфейсом консоли.
   - Отвечает за отображение меню, обработку ввода пользователя и вызов соответствующих методов для выполнения операций.

3. **CMakeLists.txt**:
   - Файл сборки проекта на CMake.
   - Определяет необходимые зависимости (Qt6, OpenSSL) и компиляционные параметры.
   - Устанавливает цель сборки `EngineeringClient`.

## Ключевые сущности

- **Session**: Представляет текущую сессию пользователя, включая информацию о профиле и токене доступа.
- **AuthResult**: Результат операции аутентификации, содержит информацию об успешности входа и данные сессии при успехе.
- **ApiClient**: Клиент для взаимодействия с API микросервиса пользователей.
- **AuthService**: Сервис для выполнения операций аутентификации и управления паролями.

## API эндпоинты

Модуль использует следующие API эндпоинты микросервиса пользователей:

1. **POST /login**: Вход в систему.
2. **GET /password-expiry-info**: Получение информации о сроке действия пароля.
3. **PUT /change-password**: Изменение пароля пользователя.
4. **POST /refresh-token**: Обновление токена доступа.
5. **POST /logout**: Выход из системы.

## Зависимости от других частей

- **common/include/userserviceclient/**: Содержит заголовочные файлы и реализацию клиентских классов для взаимодействия с микросервисом пользователей (`ApiClient`, `AuthService`).
- **API_Gateway**: Предоставляет доступ к микросервисам через единую точку входа.
- **USER_service**: Микросервис, предоставляющий API для управления учетными записями пользователей.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительский компонент (CLIENT)**: `engineering_client` является подмодулем клиента ERP системы и интегрируется в общую архитектуру через CMake.
- **Дочерние компоненты**: Модуль не имеет дочерних компонентов, но использует классы из директории `common/include/userserviceclient/` для взаимодействия с API микросервиса пользователей.
