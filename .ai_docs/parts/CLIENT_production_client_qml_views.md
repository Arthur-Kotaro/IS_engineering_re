# Часть: CLIENT/production_client/qml/views

## Назначение этой части

Часть `CLIENT/production_client/qml/views` проекта ERP для инжиниринговых компаний отвечает за представление различных визуальных интерфейсов пользователя (UI) на стороне клиента. Она содержит QML-файлы, которые определяют внешний вид и поведение основных экранов приложения.

## Основные компоненты и их ответственность

1. **DashboardView.qml**: Представляет главный экран приложения с обзором ключевых метрик и данных.
2. **MastergraphView.qml**: Отвечает за отображение графиков и диаграмм, связанных с основными показателями проекта.
3. **ProjectsView.qml**: Предоставляет интерфейс для управления и просмотра списка проектов компании.
4. **SettingsView.qml**: Содержит настройки приложения, такие как учетные данные пользователя, параметры подключения к серверу и другие предпочтения.

## Ключевые сущности

- `userData`: Объект, содержащий информацию о пользователе (например, имя, права доступа).
- `offlineMode`: Булево значение, указывающее, находится ли приложение в режиме офлайн.
- `Colors.background`: Цвет фона для всех представлений.

## API эндпоинты

В данной части проекта нет прямого определения API эндпоинтов. Однако, эти представления взаимодействуют с бэкендом через API, которые описаны в других документах проекта:
- `.ai_docs/api/endpoints.md`

## Зависимости от других частей

1. **CLIENT/common**: Содержит общие компоненты и модели данных, используемые различными представлениями.
2. **API_Gateway**: Отвечает за маршрутизацию запросов между клиентом и бэкендом.
3. **USER_service**: Обрабатывает аутентификацию и управление пользователями.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `CLIENT/production_client/qml`: Это директория, содержащая все QML представления приложения.
  
- **Дочерние компоненты**:
  - Внутри каждого представления могут быть дополнительные вложенные элементы (например, кнопки, текстовые поля), которые определяются внутри соответствующего файла QML.

Эта часть проекта является ключевой для обеспечения пользовательского интерфейса и взаимодействия с данными приложения.
