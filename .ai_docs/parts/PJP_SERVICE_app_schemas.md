# PJP_SERVICE/app/schemas

## Назначение этой части

Компонент `PJP_SERVICE/app/schemas` отвечает за определение структур данных, используемых в сервисе управления Проектными Жизненными Планами (PJP). Эти схемы используются для валидации входных данных и формирования ответов API. Они обеспечивают согласованность данных между различными частями системы.

## Основные компоненты и их ответственность

1. **draft.py**: Содержит модели данных, связанные с черновиками Проектных Жизненных Планов (PJP). Включает в себя модели для создания, обновления и публикации черновиков.
2. **pjp.py**: Определяет основные модели данных для управления Проектными Жизненными Планами, включая детали частей (PJPPartBase) и статусы PJP.
3. **validation.py**: Предоставляет модели для представления ошибок и предупреждений при валидации данных.

## Ключевые сущности

1. **PJPDraftCreate**: Модель для создания черновика PJP.
2. **PJPDraftResponse**: Модель ответа для получения информации о черновике PJP.
3. **PJPPartBase**: Базовая модель данных для частей PJP, включая поля с различными атрибутами части.
4. **PJPBase**: Базовая модель данных для PJP, включающая общие поля.
5. **ValidationError**: Модель для представления ошибок при валидации данных.
6. **ValidationResponse**: Модель ответа для представления результатов валидации.

## API эндпоинты

В данном компоненте не определены конкретные API эндпоинты, так как он содержит только модели данных. Однако эти схемы используются в контроллерах и маршрутизаторах FastAPI для обработки запросов к сервису PJP.

## Зависимости от других частей

1. **app.models.pjp**: Модели данных, используемые для взаимодействия с базой данных PostgreSQL.
2. **pydantic**: Библиотека для валидации данных и сериализации моделей.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `PJP_SERVICE/app`: Общий каталог приложения, который использует данные схем для обработки запросов.
  
- **Дочерние компоненты**:
  - Непосредственно в данном каталоге нет дочерних компонентов, но модели данных используются различными модулями сервиса PJP.

Этот документ описывает структуру и назначение схем данных в сервисе управления Проектными Жизненными Планами (PJP_SERVICE).
