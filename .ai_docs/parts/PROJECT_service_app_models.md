# PROJECT_service/app/models

## Назначение этой части

Компонент `PROJECT_service/app/models` отвечает за определение структуры данных и моделей базы данных для управления проектами в ERP-системе для инжиниринговых компаний. Эти модели используются для хранения информации о проектах, их участниках и других связанных с ними данных.

## Основные компоненты и их ответственность

1. **`__init__.py`**: Инициализационный файл модуля, который импортирует основные модели (`Project`, `ProjectStatus`, `ProjectMember`) для использования в других частях сервиса.
2. **`project.py`**: Определяет модель данных для проектов, включая их статусы и связи с участниками.
3. **`project_member.py`**: Определяет модель данных для участников проектов, включая их роли и временные метки присоединения к проекту.

## Ключевые сущности

1. **Project**:
   - `project_id`: Уникальный идентификатор проекта.
   - `title`: Название проекта (обязательное поле).
   - `description`: Описание проекта (опциональное поле).
   - `status`: Статус проекта, который может быть одним из следующих: DRAFT, ACTIVE, SUSPENDED, COMPLETED, CANCELLED.
   - `created_by`: Идентификатор пользователя, создавшего проект (обязательное поле).
   - `created_at`: Время создания проекта.
   - `updated_at`: Время последнего обновления проекта.
   - `members`: Связь с участниками проекта.

2. **ProjectMember**:
   - `id`: Уникальный идентификатор записи участника проекта.
   - `project_id`: Идентификатор проекта (обязательное поле).
   - `user_id`: Идентификатор пользователя, являющегося участником проекта (обязательное поле).
   - `role`: Роль пользователя в проекте (по умолчанию "member", возможные значения: owner, manager, member).
   - `joined_at`: Время присоединения пользователя к проекту.
   - `project`: Связь с проектом.

## API эндпоинты

В данной части кода не определены конкретные API-эндпоинты. Однако, можно предположить, что они будут использоваться для создания, обновления и получения информации о проектах и их участниках. Примеры возможных эндпоинтов:
- `POST /projects`: Создание нового проекта.
- `GET /projects/{project_id}`: Получение информации о проекте по его ID.
- `PUT /projects/{project_id}`: Обновление информации о проекте.
- `POST /projects/{project_id}/members`: Добавление участника в проект.
- `DELETE /projects/{project_id}/members/{user_id}`: Удаление участника из проекта.

## Зависимости от других частей

1. **`app.database.Base`**: Используется для определения базовой модели SQLAlchemy, на которой строятся все остальные модели.
2. **`enum`**: Модуль стандартной библиотеки Python, используемый для определения перечислений (например, `ProjectStatus`).

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**: Модели взаимодействуют с базой данных через SQLAlchemy ORM.
- **Дочерние компоненты**: Эти модели используются в контроллерах и сервисах для обработки запросов, связанных с проектами и их участниками.

Этот компонент является фундаментальным для управления данными о проектах и их участниках в ERP-системе.
