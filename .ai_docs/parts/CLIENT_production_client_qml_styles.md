# CLIENT/production_client/qml/styles

## Назначение этой части

Эта часть проекта отвечает за стилизацию пользовательского интерфейса клиента ERP для инжиниринговых компаний, используя QML. Она определяет общие стили, цветовые схемы и типографику, которые будут применяться в различных компонентах приложения.

## Основные компоненты и их ответственность

1. **AppStyle.qml**:
   - Инициализирует стиль приложения.
   - Определяет размеры отступов, радиусы скругления и тени для различных элементов интерфейса.

2. **Button.qml**:
   - Определяет внешний вид кнопок в приложении.
   - Управляет цветом фона кнопки в зависимости от состояния (активна, наведена курсором, нажата).
   - Настройка текста на кнопке.

3. **Colors.qml**:
   - Определяет цветовые схемы для темной и светлой тем.
   - Предоставляет функции для переключения между темами (`setDarkTheme`, `setLightTheme`).

4. **Typography.qml**:
   - Определяет размеры шрифтов и их веса для различных элементов текста (заголовки, основной текст, кнопки, подписи и т.д.).

## Ключевые сущности

- **AppStyle**: Содержит свойства стилей приложения.
- **Button**: Компонент QML для создания кнопок с определенными стилями.
- **Colors**: Объект для управления цветовыми темами.
- **Typography**: Определяет типографические стили.

## API эндпоинты

В данной части проекта нет прямого взаимодействия с API, так как это модуль стилей QML. Однако он может использоваться в других частях приложения для обеспечения согласованного внешнего вида элементов интерфейса.

## Зависимости от других частей

- **CLIENT/production_client/qml**: Используется для определения внешнего вида различных компонентов пользовательского интерфейса.
- **API_Gateway**: Не прямая зависимость, но стили могут влиять на восприятие данных, получаемых от API.

## Взаимодействие с родительскими/дочерними компонентами

- **Родительские компоненты**:
  - `CLIENT/production_client/qml`: Использует стили для создания пользовательского интерфейса.
  
- **Дочерние компоненты**:
  - Отсутствуют, так как это модуль стилей.

Этот модуль предоставляет общий набор стилей и цветовых схем, которые могут быть использованы в различных частях приложения для обеспечения согласованного внешнего вида.
